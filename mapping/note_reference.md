# 32 键音名 / 简谱 / 五线谱对照

简谱按 **1=C** 或 **1=F** 两种固定写法；`'` 表示简谱数字上方一个八度点（`''` 两个，`'''` 三个），`#` 是升号。
五线谱位置按**高音谱表**，从下往上数；`上加N线` 是五线谱上方的加线。
