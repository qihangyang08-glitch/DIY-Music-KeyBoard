## 0. 自动化与可选项原则

**默认就该发生的事（零配置）：**

- 插上 USB 自动找 COM 口、自动重连、自动恢复上次的 profile 和曲谱。
- 数据谱（MIDI/MusicXML）自动跟随、自动滚动、自动高亮下一键、自动给映射建议。
- 图片谱默认手动翻页；不假装能跟随。
- 当前映射范围、下一键、设备状态始终可见，不需要进设置页确认。
- 只有信号明显变差时才提示校准，不主动打断演奏。

**必须保留的开关（默认值 + 一个开关，不要求用户懂原理）：**

| 开关 | 默认 | 位置 |
|---|---|---|
| Auto 跟随乐谱（映射） | 开 | 右侧映射卡 / Pad 4 长按 |
| 自动滚动 | 开 | 演奏页右上 / 设置 |
| 下一键提示 | 开 | 演奏页右上 / 设置 |
| 自动翻页（图片谱） | 关 | 设置（后续） |
| 4 个 Pad 的功能 | SUS / OCT− / OCT+ / MAP | 设置 → 设备 |
| 主题 | Studio | 设置 |
| 语言 | 中文 | 设置 |
| 高级参数（release grace / legato / 固定 velocity） | 合理默认 | 设置 → 高级 |

**简单模式 / 高级模式：**

- 默认“简单模式”：只出现演奏、映射开关、音色、八度、校准入口。
- “高级模式”才显示延迟、阈值、日志、固件、release grace 等。
- 每个自动行为都能单独关；关掉后行为退回手动，不隐藏入口。

## 1. 产品定位

把 32 键电容琴做成“打开就能弹、能看谱、按键有反馈、状态一眼清楚”的桌面乐器，而不是一个 DAW。

三条原则：

- **演奏优先**：默认进入演奏页；谱面、键盘、按键特效占主要面积。
- **专业能力、业余界面**：底层有映射、校准、MIDI、音色；界面上只出现“音色、映射、八度、校准”这些直白词。
- **把复杂收起来**：设备地址、通道、电极放进“设备/校准”页；主界面只显示 3 个模块灯和异常提示。

明确不做：

- **力度/velocity**：探针结果显示这个传感器对距离远比对压力敏感，连续力度不现实；固定 velocity，表达靠时长、释放、滑音和音色。
- 多轨编曲、VST 宿主、专业混音、制谱编辑、深层参数树。
- 主要操作不超过两次点击。

## 2. 视觉方向

关键词：**黑白、磨砂玻璃、高对比、轻木质、克制**。

- 主色：近黑 `#101012`、纸白 `#F6F6F3`、若干透明度灰。
- 强调色：暖铜金 `#D8A24A`，只用于按下键、引导高亮、录音、校准进度。
- 警示：砖红 `#B94A3E`；成功态不用绿色，用白色/金色。
- 木质：键盘外框/底部一条，浅橡木纹理、低透明度；不做整屏木纹。
- 磨砂玻璃：半透明面板 + 预渲染背景模糊，避免实时模糊拖性能。
- 字体：Noto Sans SC / 思源黑体；音名/数值用等宽（JetBrains Mono / Cascadia Mono）。
- 圆角：面板 20 px，按钮 12 px；1 px 半透明描边；轻阴影。
- 动效：120–180 ms；按下的向上波纹 450–600 ms；不做弹跳和炫光。

两套主题：

| 主题 | 背景 | 面板 | 文字 | 用途 |
|---|---|---|---|---|
| **Studio（默认）** | 纸白 | 磨砂白 65% | 近黑 | 白天、练琴、日常 |
| **Stage** | 近黑 | 白色 7% | 纸白 | 暗光、投影、演出 |

## 3. 信息架构

左侧窄栏（可收起）：`演奏`、`曲谱`、`校准`、`设备`、`音色`；底部 `设置`。

顶部常驻：

- 左：3 个模块灯 + “3 模块在线”。
- 中：`Map · Chromatic · F4–C7`（点击切换映射）+ `profile · 裸铜`。
- 右：延迟、采样率、音量、设置。

演奏页可全屏，隐藏左栏和右侧面板。

快捷键：

| 键 | 动作 |
|---|---|
| Space | 播放/暂停曲谱 |
| Esc | Panic |
| `[` `]` | 八度 −1 / +1 |
| `-` `+` | 移调 −1 / +1 |
| `1`–`4` | 切换映射预设 |
| `M` | 循环映射（含 Auto） |
| `P` | 切换音色 |
| `C` | 校准 |
| `F` | 全屏 |

### 4.1 顶部引导条（扁长 32 键）

- 高 44–48 px，横跨内容区，位于状态条下方、谱面之上。
- 32 个细长小键，按物理顺序 F4–C7；当前映射的每个键可显示一个很淡的音名刻度。
- **下一键高亮**：解析类乐谱播放/跟弹时，高亮接下来 1–3 个该按的键（暖金脉冲）；左侧显示 `NEXT: C5 · E5`。
- 右侧显示当前映射范围 `MAP F4–C7`；自动映射切换时出现一个小箭头/过渡。
- 图片谱没有跟随数据时，左侧显示 `无跟随 · 手动翻页`，高亮只反映你实际按下的键。
- 点击引导条上的键可以试听/定位（可关闭）。

### 4.2 中央谱面区

- 三种内容：
  1. **图片**：PNG/JPG/PDF；缩放、平移、翻页；只显示，不跟随。
  2. **可解析数据**：MIDI/MusicXML；渲染成谱面或落键视图；有播放头、当前小节高亮、下一键指示、自动滚动。
  3. **落键**：钢琴卷帘，与底部键盘对齐；力度不显示（固定），音符高度只表示时值。
- **下边界渐模糊**：谱面底部 60–80 px 做渐变 + 轻模糊，淡入键盘区；不遮挡音符文字，只作用于边缘。
- 空态：中间大拖放区“拖入 MIDI / MusicXML / 图片”；下方最近曲谱。
- 图片谱与可解析谱的差别只在“跟随/指示/自动映射”，演奏和键盘特效完全一致。

### 4.3 底部演奏键盘

- 32 键 F4–C7，按物理布局（黑键分组），白键标注音名；可切换键号。
- **按下波纹**：从键位向上发出一道柔和的渐变光柱（宽略大于键），上升约 100–140 px 后在 450–600 ms 内渐弱消失；和弦多柱并行；滑音形成短拖尾。
- 强度**不来自压力**：固定亮度 + 时长/音高做轻微差异；不要让用户以为按得重会更亮。
- 按下的键黑白反转 + 暖金描边；鼠标点击可试听。
- 底部边缘与木框之间保留 1 px 高光；Stage 主题下光柱为白色。

### 4.4 右侧面板

- 音色卡（钢琴、电钢、管风琴、弦乐、合成器）。
- **映射卡**：当前映射名 + 范围；`Auto 跟随乐谱` 开关；预设快捷 chips。
- 八度、移调大数字 + 复位。
- 录音、Panic。
- 不再有力度曲线。

### 4.5 4 个剩余键（pads）

物理位置：模块 3 的 E8–E11（通道 33–36），放在 32 键右侧，做成 2×2 的四个圆角小 pad，和木框同宽，不混入钢琴键。

默认用途（可在设置里改）：

| pad | 默认 | 说明 |
|---|---|---|
| 1 | **Sustain 延音** | 按住延音；设置里可选“点按锁定/解锁” |
| 2 | **Oct −** | 八度 −1，快速换音区 |
| 3 | **Oct +** | 八度 +1 |
| 4 | **Map** | 短按循环映射；长按切换 `Auto 跟随乐谱` |

为什么这样分：

- 延音是演奏上最有用的“第三只手”。
- 八度 ± 是 32 键最需要的快速移位；比去摸 UI 快。
- 映射切换是新功能里最值得给物理键的；长按进入 Auto，避免误触。
- Panic 保留在 UI；也可以在设置里把 pad 4 改成 Panic 或“播放/暂停”。

可选备用用途（可配置）：播放/暂停、翻页、节拍器、移调 ±、映射预设 1–4。
四个 pad 都是电容键，**长按/短按**可区分；不建议做力度。

## 5. 曲谱与跟随

### 5.1 支持的格式

| 格式 | 显示 | 跟随/指示 | 自动映射 |
|---|---|---|---|
| MIDI `.mid` | 落键 / 转谱面 | 是 | 是 |
| MusicXML `.musicxml/.mxl` | 谱面（Verovio） | 是 | 是 |
| PNG/JPG | 图片页 | 否 | 手动 |
| PDF | 图片页 | 否（后续可做 OMR） | 手动 |
| `.mscz` | 暂不支持 | — | — |

- 图片谱：只做翻页/缩放；顶栏引导条显示“无跟随”，但仍显示你按下的键和当前映射。
- 可解析谱：播放头、当前小节高亮、下一键高亮、自动滚动、跟弹。
- 后续可加 OMR（Audiveris）把图片转成可解析谱，但不在第一版。

### 5.2 跟随与指示

- 播放头随“曲谱时钟”移动；当前小节淡金色底。
- 下一键：顶栏引导条高亮未来 1 拍/300 ms 内的音符；和弦同时亮多个。
- 跟弹：先做“播放 + 跟弹”，不做“弹对才继续”；后者放后续。
- 自动映射切换时，谱面出现一个小箭头标记，顶栏范围同步更新。

## 6. 映射（Map）系统

32 键的物理范围是固定的，映射决定“每个键当前发哪个音”。

### 6.1 映射预设

- **Chromatic**：默认 F4–C7，32 个半音。
- **Octave shift**：同一套半音，整体 ±1/±2 八度。
- **C Major / A Minor**：白键音阶铺满 32 键，覆盖更宽的音域；半音经过音会缺失。
- **Pentatonic**：五声音阶，适合简单旋律/即兴。
- **Auto（跟随乐谱）**：根据当前可解析乐谱自动选窗口。

### 6.2 快捷切换

- 顶栏 `Map` chip：点开快捷选择（预设 + 八度/移调 + Auto）。
- 快捷键 `1`–`4` 切预设，`M` 循环，`[` `]` 八度，`-` `+` 移调。
- **Pad 4** 短按循环映射，长按切换 Auto。
- 切换时：底部键盘音名、顶栏范围、谱面高亮同步更新；toast 显示新范围；按住的音保持原音高，松开后再用新映射。

### 6.3 Auto 跟随乐谱

1. 读取全部音符的音高范围。
2. 若跨度 ≤ 32 个半音：整体平移/八度，一次适配；显示 `Auto · C3–G5`。
3. 若跨度 > 32：按音符密度/旋律线选一个 32 键窗口；在休止或小节边界自动切换窗口；跨度同时超过（如双手大跨度）时给出警告，不假装能覆盖。
4. 图片谱：Auto 不可用，只能手动选预设/八度。
5. 每个曲谱可记住自己的映射；切歌时恢复。

## 7. 校准（只做阈值，不做力度）

保留校准是因为裸铜和成品面板的信号差很多，阈值/噪声必须适配；但不再采集轻/重力度。

流程：

1. **准备**：profile 名称、包装（裸铜 / 2 mm PVC / 自定义）。
2. **静置**（6–10 s）：采集每键噪声底。
3. **悬停**：手指离键 1–2 cm；采集 hover delta，用于把 touch 阈值设在悬停之上。
4. **逐键确认**：按顺序轻触每个键，确认能稳定触发；可跳过/重做。
5. **结果**：32 键噪声/hover/触发热图；弱键、噪声键（ch24/25）列表；建议阈值；保存 profile。

Profile 字段：包装、日期、增益、每键 `noise / hover / touch_threshold / release_threshold / status`。没有 velocity 曲线。
固件需要：上报 active 键 magnitude、支持每键阈值；不需要力度映射。

## 8. 设备页

- 3 张模块卡：模块 1/2/3、地址、通道范围、在线/离线、错误计数、最近重连。
- 4 个 pad（通道 33–36）单独一行：功能、按下状态、校准值。
- 通道表：key、音名、channel、module/electrode、信号健康、最近 delta、blip 次数。
- 原始监视：32/36 条 delta 柱状图；用于查虚焊/悬停误触。
- 事件：out-of-range、I2C 错误、心跳丢失、re-init；提供“重新初始化”“地址探测”。
- 用人类语言：`模块 1 · 左侧 · 键 1–12`。

## 9. 音色页

- 音色卡：钢琴、电钢、管风琴、弦乐、合成器（GM program 在底层）。
- 音量、混响、亮度（FluidSynth 支持范围内）。
- 输出：内嵌 FluidSynth / 外部 MIDI（DAW）；音频设备、缓冲/延迟。
- SoundFont 导入收在“更多”。
- **固定 velocity**：提供一个全局 1–127 的滑块（高级），默认 100；不做按键力度。

## 10. Profile 与设置

- Profile：列表、当前、复制、导入/导出 JSON、删除；包装标签。
- 设置：主题（Studio/Stage）、语言（中文/English）、键位标签、全屏、release grace/legato、4 pad 功能映射、日志目录。
- 数据：曲谱库、profile、会话日志；可导出/清理。

## 11. 状态与反馈

- 空态：没有曲谱/没有校准/没有设备，各有一句下一步行动。
- 设备离线：状态条变红，不阻塞演奏；自动重连。
- 图片谱：顶栏“无跟随”提示；自动映射/下一键指示禁用。
- 映射切换：toast + 顶栏范围动画；按住的音不追改。
- 4 pad：按下高亮；Sustain 锁定状态显示小点；Map 长按有 300 ms 进度环。
- 录音中：顶部红点 + 时间；停止后可保存 MIDI。
- 无按键反馈：提示“信号弱，建议校准”，不弹模态框。

## 12. 技术架构（PySide6）

```
pc/app/
  main.py
  core/
    serial_service.py      # QThread 读串口，发 Qt signal
    note_engine.py         # 复用原型，固定 velocity
    synth_service.py       # FluidSynth 封装，音频线程
    mapping.py             # 32 键映射、预设、Auto 跟随
    score_import.py        # MIDI/MusicXML/图片
    score_render.py        # Verovio -> SVG
    calibration.py         # 噪声/悬停/阈值，无力度
    profiles.py            # JSON profile
    session_log.py
  ui/
    main_window.py
    perform_view.py
    guide_strip.py         # 顶部扁长 32 键
    keyboard_widget.py     # 底部 32 键 + 波纹
    score_view.py
    falling_notes.py
    calibrate_view.py
    device_view.py
    sound_view.py
    library_view.py
    pads_widget.py         # 4 个剩余键
    widgets/glass_panel.py, meters.py, ...
  resources/ (fonts, icons, default profile, sf2)
```

- 串口、音频、渲染都不在 UI 线程；全部 Qt signal/slot。
- 单一 `AppState` 持有设备、音符、映射、profile、曲谱位置。
- 顶部引导条与底部键盘共用同一个映射模型，高亮/音名天然一致。
- 下边界模糊：谱面底部叠加渐变遮罩 + 预渲染模糊快照；不做实时高斯。
- 波纹特效：QPainter/QML 粒子层，限制并发数（例如 24 条），460 ms 生命周期；不阻塞绘制。
- 谱面：Verovio（MusicXML→SVG）、music21/mido（MIDI）、QtPdf（PDF）。
- 打包：PyInstaller/Nuitka，带 FluidSynth DLL + SF2。

## 13. 分阶段

- **P1 演奏壳**：主窗口/左栏/状态条、顶部引导条、谱面容器（图片+占位）、底部 32 键 + 波纹、4 pads、映射预设/快捷切换、音色/八度/移调/Panic、Studio/Stage。
- **P2 曲谱跟随**：MIDI/MusicXML 解析、谱面/落键、播放头、下一键高亮、自动滚动、Auto 映射；图片谱翻页。
- **P3 校准与设备**：噪声/悬停/阈值校准、profile、设备诊断、4 pad 功能设置。
- **P4 打磨**：录音/导出、跟弹模式、打包、性能、无障碍。

## 14. 默认值与实现顺序（设计收口，不再讨论细节）

以下都是**默认行为**，不是需要用户先回答的问题；实现时先按这个做，后续可改。

1. **Auto 映射**：数据谱默认开。跨度 ≤32 半音一次适配；超过时按乐句/小节自动换窗口，顶栏显示当前窗口；同一时刻跨度就超过 32 半音则警告。用户可在映射卡/Pad 4 长按关掉 Auto，手动换。
2. **图片谱**：首批 PNG/JPG；PDF 第二阶段（QtPdf）。默认手动翻页；自动翻页开关后续加。图片谱不显示“下一键”，只显示当前按下的键。
3. **4 pads**：默认 `SUS / OCT− / OCT+ / MAP`；Pad 4 短按循环映射、长按 Auto。全部可在设置里改；Panic 保留在 UI。
4. **跟弹**：P1–P2 先做“播放 + 跟弹 + 下一键提示”；“弹对才继续”放 P4。
5. **录音/导出**：P1 只放录音按钮占位，实际录音/导出放 P4。
6. **主题/语言**：Studio + 中文默认；Stage 和 English 都是一键开关。
7. **力度**：固定 velocity（高级里可调全局值），不做按键力度。
8. **视觉细节**：v2 视觉稿作为 P1 基线；波纹高度、模糊范围、pad 尺寸、右侧面板宽度都可以在实现中调，不再单独评审。
