## 运行

**一键启动**：双击 `pc\run.cmd`，或在项目根目录执行：

```
python pc/app/main.py
```

也可以在 VS Code 里运行任务 **Run KeyBorad PC**（`.vscode/tasks.json`）。
`run.cmd` 会把工作目录切到仓库根目录，所以从资源管理器双击也能正常找到
`pc/resources/` 下的谱面与 SoundFont。

**常用参数**：

```
python pc/app/main.py --port COM5          # 指定串口（默认自动找 ESP32-S3）
python pc/app/main.py --no-serial          # 只用电脑键盘，不打开串口
python pc/app/main.py --no-audio           # 静音（只看界面）
python pc/app/main.py --theme stage        # 直接进 Stage 主题
python pc/app/main.py --size 1280x800      # 换个窗口大小
python pc/app/main.py --progress dev.json  # 开发用：另存学习进度，不碰用户配置
python pc/app/main.py --library dev_scores # 开发用：导入曲谱放这里，不碰用户曲库
python pc/app/main.py --screenshot pc/mockups/p1_5_ui_studio.png  # 开发截图
```

**连接真机**：固件通过 USB-Serial/JTAG 输出 32 键 + 3 个 MPR121 模块；应用
自动识别（本机为 `COM5`）。同一时刻只能有一个程序占用串口——**先关闭
PlatformIO 的串口监视器**，再启动应用；否则状态条会一直显示“等待设备”。
强制端口用 `--port COM5`。声音由 FluidSynth 输出，顶栏显示 `48 kHz` 表示
音频正常；没有音频设备时自动降级为静音并给出提示。

**测试**：

```
cd pc
python -m unittest discover -s tests -v
```

也可以在 VS Code 运行任务 **Test KeyBorad PC**。

**依赖与资源**：Python 3.11 + `pc/requirements.txt`（PySide6 6.12、pyserial、
pyfluidsynth）。FluidSynth DLL 与 TimGM6mb SoundFont 在
`pc/prototype/vendor/`；`synth_service.py` 也会搜索 `pc/vendor/` 与
`pc/resources/`。用户数据（`learning.json`、`keybindings.json`、
`accessibility.json`、`scores/`、`projects/`、`score_prefs.json`）在 Windows 的
`%LOCALAPPDATA%\KeyBorad\`，删除前请先备份。

**公开版构建（H9a）**：

```
cd pc
python tools/build_public.py            # 写 dist/public_content.zip
python tools/build_public.py out.zip    # 指定输出路径
```

构建按 `app/core/release.py` 的白名单打包 `resources/`：课程里
`visibility="private"` 的内容（当前《梦中的婚礼 · 片段》）及其 MusicXML/MIDI、
项目里 `visibility` 非 public 或 `public_release != "yes"` 的模板会被剔除；
`user-data/`、`learning.json`、`score_prefs.json`、`keybindings.json`、日志、
缓存与 `mockups/` 永不进入包内。包内附 `PUBLIC_CONTENT.md`（包含/移除清单）与
`public_exclusions.json`。任一校验失败（缺谱、私有文件泄漏、路径不安全）都会
退出非零且不留下压缩包。私有内容仍保留在本机，照常可练。

## 电脑键盘（没有硬件时）

三行顺序、从左到右、从低到高（物理键码绑定，中文输入法开启时仍按位置工作）：

| 光条 | 1–10 | 11–21 | 22–32 |
|---|---|---|---|
| 电脑键 | `Z X C V B N M , . /` | `A S D F G H J K L ; '` | `Q W E R T Y U I O P [` |

- `Tab` / `Shift+Tab`：在导航、设置、走带等控件间移动焦点；`Enter` / `Space`
  激活当前控件（焦点在按钮上时，`Space` 不再触发播放/暂停）。
- `Ctrl+Tab`：显示 / 隐藏每个槽的键帽与音名。
- `Shift`：按住延音（松开的音继续响）。
- `Space`：播放 / 暂停示例谱（焦点不在按钮上时）；`Esc`：全部静音。
- 鼠标只用于页面、功能胶囊和设置；**点击光条不发声、不产生光柱、不推进任何
  状态**（v3 §5.1）。
- 键盘无冲：同时按 6 个以上键可能丢音；和弦多时优先用实体琴。

## 硬件输入

固件仍然输出：

```
[  10972 ms]  0x5A OK  0x5C OK  0x5D OK   keys: 12
```

校准命令（切片 2，已上真机）：

```
CAL <millis> <32 values>        # c 开启；0..255，-1 = 模块离线
T <channel> <touch> <release> ...   # -> OK T / ERR T <channel> / ERR T 0
Q                               # -> T ... 当前 32 组阈值
```

`CAL` 的值是 `clamp(baseline - filtered, 0, 255)`，触摸为正值。PC 端
`core/calibration.py` 负责解析与曲线逻辑，`ui/calibration_page.py`
负责页面、阈值选择、应用/保存与多指验证。

`core/serial_service.py` 在后台线程读串口，自动识别 ESP32-S3 的原生 USB
（VID `303A` / PID `1001`），断开后每秒重试。硬件按键和电脑键盘进入同一个
20 ms 引擎；状态条显示当前来源（`琴` / `电脑键盘` / `琴 + 电脑键盘`）。

同一时刻只能有一个程序打开串口。如果状态栏显示“等待设备”，先关掉 VS Code /
PlatformIO 的串口监视器，或加 `--port COM5`。

## 曲谱跟弹（P2 切片）

启动后会自动载入内置的公有领域样曲《小星星（片段）》：

- `pc/resources/scores/xiaoxingxing.musicxml` / `.mid`；
- 解析器在 `core/score.py`，不依赖 music21/mido；样曲由
  `pc/tools/make_sample_score.py` 生成。

演奏页的 **落键** 视图显示真实音符、播放头和当前/下一键：

- **跟弹**：顶栏、顶部提示带和底部光条都显示下一键（音名 + 光条号）。
  按对会推进并计数；按错不清空期望键，只记一次未中并让目标光条闪红。
  `重来` 回到开头重新练习。
- **示范**：`Space` 播放/暂停。播放头、自动滚动、光条光柱和声音跟随谱子；
  示范播放不参与判定。`Space` 再按暂停，`Esc` 全部静音并停止示范。
- **自动跟随**：右栏开关打开后，按小节/乐句把曲子切成最多 4 小节一段的窗口，
  每段选一个八度让 32 条键覆盖该段音高；只在段边界换窗，段内手动调八度会保留。
  映射卡显示当前窗口与段号（如 `F2–C5 · 1/2 段`）；整曲只有一个窗口时只显示
  音域。有休止（≥ 1 拍）或每 4 小节处会形成新的候选分段。
- **换谱**：把 `.musicxml` / `.mxl` / `.xml` / `.mid` / `.midi` 拖到谱面卡片上；
  解析失败会给出中文提示。
- **音域不够**：如果当前映射找不到目标音高，顶栏会显示“超出音域”；调整
  八度/移调或换映射即可。
- **按学习条目自动套用映射（H7f）**：内容条目可以声明映射预设 key 或
  结构化 `MappingSpec`（当前「左右分区 · 8 小节」声明分界 16、左 C3 半音、
  右 C5 半音）。学习页打开练习、或曲库直接打开该曲目卡片时自动切换，并把
  八度/移调归零（结构化声明可用自己的偏移）；映射在解析成功后、生成自动
  跟随窗口前生效。返回学习、载入别的谱、换卡片、打开项目/训练/显示类文件
  时恢复你原来的预设/八度/移调/自动跟随。练习中仍可临时改映射，退出时丢弃。
  曲库按文件 stem 反查课程声明；导入文件不继承内置声明。
- **白键 19 键预设（H7f）**：映射菜单新增「白键 19 键」——C4–G6 的 19 个
  白键映射到键 1–19，键 20–32 禁用。禁用槽在光条上画暗并显示“—”，按键
  不发声；范围显示 `C4–G6`，自动跟随把禁用音视为不可达。
- **拖拽分区点（H7f）**：当前映射带左右分区时，光条上的琥珀线会加粗并带
  一个小握把，可以左右拖动（1–31）；右栏映射卡同时显示「分区 16 · 拖动
  光条琥珀线调整」，悬停线时也有提示。拖动实时生效，松手后按当前曲目保存到
  `score_prefs.json`（内置曲目按文件名、导入按路径），再次打开自动恢复，
  换谱清除。**这是有意的按曲目持久化**；想回到内容默认分区，点右栏的
  「重置」即可（同时清除本曲目的保存值）。红色项目分区线是创作页的轨道
  分区，不受影响。
- **黑白键方位提示（H7f）**：光条静息时，黑键槽位有自上而下的明显暗色
  渐变和顶部小点；按下/下一键/错误提示的绘制不变，槽位仍等宽，不画钢琴键
  轮廓。
- **自动跟随说明**：开关的 tooltip 与右栏范围行会说明「按乐句自动切换
  32 键八度窗口」；关闭时保持手动映射与八度。
- **左手自动伴奏（H7e）**：学习内容可以把某个 MusicXML part 声明为伴奏
  （当前为阶段 5「小星星 · 自动左手」的 `P2`）。打开后只把其余 part 交给你
  跟弹；伴奏由 FluidSynth 在独立通道 10 自动演奏，不进入判定、命中数和
  窗口规划。练习时按键就是节拍：右手指到哪一拍，左手补上到该拍的伴奏音，
  越过音符结束时间自动松开；`Space` 示范时双手一起响。曲库直接打开同一
  文件仍按整谱练习（曲库没有内容声明）。

解析器当前支持的子集：MusicXML 所有 part 的 divisions/time/key/tempo、
音符/休止/和弦/backup/forward，并保留每个音的高音谱表拼写
（`step/alter/octave`）；MIDI format 0/1、PPQ、note on/off、set_tempo、
拍号、调号（`key_fifths`）、连音线合并、反复/结尾展开。暂不支持：
SMPTE 时间、装饰音、圆滑线、五线谱高级排版（自动分页）；遇到不支持的
结构会跳过并给出中文提示。落键网格按首段速度画拍/小节；变速曲目的网格
精度在后续版本处理。自动换窗口按解析出的 `measure` 字段分段，不依赖
五线谱渲染。

## 曲谱库（P4 切片）

曲谱库从磁盘实时派生，没有清单文件、没有缓存，也没有“看起来有、其实打不开”
的卡片：

- **内置**：扫描 `pc/resources/scores/`。当前 **32 个可跟随文件**：21 首
  入门/双手/完整曲（13 首公有领域入门曲 + 《欢乐颂 · 自动左手》
  《两只老虎 · 自动左手》 + 原创《小步舞曲》《五指位置 · G/F》
  《反向与平行 · 8 小节》《弱起与反复 · 8 小节》+《致爱丽丝 · 主题》+ 私有
  《梦中的婚礼 · 片段》）+ 11 条本项目训练（阶段 3–6 的音阶/
  音程/连奏、和弦/琶音/3/4 华尔兹、左右分区/慢速/固定伴奏/自动左手、
  反向平行/困难小节循环、乐句/速度/连奏断奏/延音踏板）。低音谱号
  训练是学习页内的生成式 drill，不产生谱面文件。`mariage_fragment` 标为
  私有，公开构建必须排除。MusicXML 与同名 MIDI 合并为一张卡，优先
  MusicXML；卡片会显示它被哪些阶段引用。
- **我的导入**：点「导入曲谱」选择 `.musicxml/.mxl/.xml/.mid/.midi`，或
  图片/PDF（仅显示）；文件会复制到用户配置目录的 `scores/`（`--library`
  可指定开发目录）。导入目录按子目录递归扫描；相同内容按 SHA-256 去重；
  同名不同内容自动加 `-2`、`-3`；解析失败的文件仍保留为可移除的
  “解析失败”卡。导入目录由 `QFileSystemWatcher` 监视，外部新增/删除后
  300 ms 内自动刷新。
- **可跟随**：只有扫描时 `parse_score` 成功的文件才会出现“MusicXML · 可跟随”
  或“MIDI · 可跟随”。扩展名本身不算数。点卡片会载入演奏页，进入正常的
  下一键/自动换窗/跟弹流程。
- **收藏/标签/最近**：卡片右上角 ★ 收藏；「标签」可输入逗号分隔的标签
  （最多 8 个），搜索会同时匹配标签；成功打开可跟谱或图片后进入「最近」
  （保留 12 条）。元数据保存在 `library_meta.json`，与曲谱文件分离。
- **仅显示**：导入 `.png/.jpg/.jpeg/.bmp/.webp/.pdf` 会生成“图片 · 仅显示”
  或“PDF · 仅显示”卡；图片可在「谱面」页查看，PDF 只提示“仅显示”，
  两种都不进入跟弹、不会被 `parse_score` 当成曲谱。
- **制作中**：只来自当前 `curriculum.STAGES` 的曲目（今天 2 首），显示阶段、
  难度与“制作中”，不可点击进入练习；不虚构 59/62/67 的内容数量。
- **筛选/搜索**：默认“可跟谱”；另有“收藏 / 最近 / 我的导入 / 全部 / 制作中”，
  以及按标题、作曲家、阶段、标签搜索。页面每次显示时重新扫描目录，但解析
  结果按 `(路径, mtime_ns, size)` 缓存在内存里：未变文件不再重解析，改写/新增/
  删除在下一次刷新可见；重启后缓存为空。坏文件不缓存，修好后立即生效。
- **移除**：只删除用户曲库里的副本，路径必须位于导入目录内（允许子目录）；
  内置曲目和源文件不受影响。移除当前正在练习的导入文件不会打断内存里的
  当前练习。
- **限制**：内置目录不做递归扫描（导入目录递归，深度 8/5000 文件/1000 目录）；
  PDF 没有内嵌渲染（无 QtPdf），只做“仅显示”提示；装饰音/圆滑线尚未支持；
  变速曲只显示首个速度；MusicXML 小节数按 `<measure>` 元素计数，MIDI 按最后
  一个带音符的小节；不做云同步。收藏/标签按曲谱卡 key 保存，改名或换目录后
  不会自动跟随。
- 拖到演奏页谱面卡片的文件仍是“本次载入”，不会自动复制进曲库；要长期保留
  请用曲谱页的“导入曲谱”。

## 快捷键

| 键 | 动作 |
|---|---|
| `Space` | 示范播放 / 暂停（有曲谱且焦点不在按钮上时） |
| `Esc` | 全部静音 |
| `Shift`（按住） | 延音 |
| `Tab` / `Shift+Tab` | 焦点遍历（方向键在导航/设置 chip 行内移动） |
| `Enter` / `Space` | 激活当前焦点控件 |
| `Ctrl+Tab` | 显示 / 隐藏光条键帽与音名 |
| `Ctrl+1` … `Ctrl+6` | 演奏 / 学习 / 曲谱 / 创作 / 设备 / 设置 |
| `Ctrl+M` | 切换音域映射 |
| `Ctrl+P` | 切换音色 |
| `Ctrl+[` / `Ctrl+]` | 八度 −1 / +1 |
| `Ctrl+-` / `Ctrl+=` | 移调 −1 / +1 |
| `F1` | 帮助 / 怎么用 |
| `F11` | 全屏 |

字母键全部留给音符；功能动作都放在 Ctrl 组合，避免“弹琴”和“快捷键”抢字母。
切到非演奏页会自动松开所有电脑键盘按住的音，避免卡音。

识谱训练页：字母键用于作答；`Space` 不播放示范，`Shift` 不延音，映射/八度/
移调快捷键被忽略。训练总结页额外支持 `Enter`/`Space` 再练一次、
`Esc`/`Backspace` 返回阶段。

节奏训练页：任意字母键踩拍；`Enter`/`Space` 开始或停止，`Esc` 停止
（停止后再按返回阶段），`Backspace` 返回阶段。

以上只是默认值；**设置 → 工具 → 键位设置** 可以改绑 32 个音符键和全部功能键，
冲突会提示替换，方案自动保存到用户配置目录的 `keybindings.json`，也可导出/导入。

## P1.5 做了什么

- **C 演出幕布光条**：32 个等宽槽连成一条半透明幕布；总高 52 px、槽高 32 px；
  无钢琴键图形、无木框；按下只有 2 px 顶部彩边 + 槽内柔光和向上光柱；标签只在
  按下时浮出；`Ctrl+Tab` 可让所有槽显示键帽/音名。
- **彩色光柱浮层**：宽而淡的外层 + 窄而亮的核心，520–700 ms 渐隐，不占布局、
  不吃鼠标；每个音高类一个色相（音高彩虹）。
- **电脑键盘 = 第二台操作器**：三行 32 键默认布局；与实体琴合并到同一个
  InputHub；同一光条被两个来源按住时，任一方松开不断音，两方都松开才停。
- **4 个功能胶囊**：延音（按住）/ 八度− / 八度+ / 映射；可鼠标点击，也可用
  `Shift` / `Ctrl+[ ]` / `Ctrl+M`；硬件 pad 33–36 仍然有效。
- **顶部 32 格提示带**：不再画迷你钢琴；显示当前按下的键（下一键/跟谱在 P2）。
- **中文优先 + 6 个导航入口**：演奏 / 学习 / 曲谱 / 创作 / 设备 / 设置；
  音色与校准收为子页；按钮、状态、主题名、音色名与映射名均中文优先，
  英文只留在术语、品牌和高级信息里。
- **键位设置页**：设置 → 工具 → 键位设置；32 个音符键和全部功能键可改绑；
  捕获时 Esc 取消；冲突提示替换；自动保存到用户配置目录，支持导出/导入与恢复默认。
- **F1 帮助**：按当前键位动态生成三行键位表和全部功能键；设置页也有入口。
- **无障碍反馈（H9b）**：对错不只靠颜色——按错的光条显示红色虚线框 + `×`，
  按对显示琥珀实线框 + `✓`，顶栏同时写「命中 / 未中 · 应按 X」。
  设置 → 辅助功能 →「减少动效」关闭光条呼吸、光柱与松键淡出；跟弹判定和
  播放头不受影响。**字号**提供 小 0.9 / 标准 1.0 / 大 1.2，统一缩放界面

## 创作页（H1 内核 + H2 页面）

创作页（导航第 4 项 / `Ctrl+4`）已从占位换成可用的录音工作台：

- `Project` / `Track` / `NoteEvent`：项目以**拍**计时；每轨有 GM 音色、音量、声像、
  静音/独奏与音符事件；循环区独立保存；项目 JSON 保存/载入，最多 8 轨，
  坏文件/坏音符按容错方式跳过。
- `Recorder`：把 note-on/note-off 的拍位置录成音符事件；停止时收尾仍按住的音；
  循环录音把后续遍次折回循环区，跨循环尾的音符在尾部裁剪。
- `Track.overdub`：叠录把新事件并入当前轨道并按时间排序，不覆盖旧内容。
- `quantize(events, grid)`：只移动起点到 1/4、1/8、1/16 网格，不改音高/时值；
  默认不启用（本切片没有量化按钮）。
- `ComposeSession`：秒→拍的转换、当前轨选择、新录音替换旧内容、叠录合并、
  循环设置、GM 音色/音量控制、项目载入都在这层；无 Qt。
- 创作页：录音 / 叠录 / 停止、4 小节循环、轨道列表（音色 →、音量 −/＋）、
  保存/载入、导出 MIDI、每轨静音/独奏；顶部红点与时长；32 条光条复用，
  鼠标点光条不发声；
  `Esc` 仍是全部静音，离开页面会先收尾当前录音。
- 项目默认路径是 `QStandardPaths.AppConfigLocation/projects/project.json`
  （Windows 上与 Roaming `%APPDATA%` 不是同一目录）；测试通过
  `MainWindow(projects_root=...)` 注入临时目录。
- 钢琴卷帘（H3）：C3–D#6 音高网格，按小节/拍画线；左键画、右键擦、拖动移动、
  Ctrl+拖动复制、拖右缘改时值、Ctrl+滚轮或按钮缩放、撤销；循环区淡色显示，
  回放时播放头随位置移动。编辑只改项目，不发声、不进跟弹判定。
- 项目回放（H4）：播放计划按项目速度把拍换成秒，应用静音/独奏与循环；
  播放器用通道 1–8，每轨独立音色/音量/声像；`Space` 或播放按钮切换，
  停止/录音/编辑/切页/静音会先停回放。无音符时不启动。
- MIDI 导出（H4 第一批）：格式 1 · PPQ 480；指挥轨写标题/速度/拍号，
  每条可听音轨一条轨，带 GM 音色、音量（CC7）、声像（CC10）；静音轨剔除，
  有独奏时只导出独奏轨。导出文件能被现有解析器重新读入。
- 每轨声像滑杆（M/S 旁边），导出 CC10 与回放通道同步；4 个创作模板一键载入
  （钢琴独奏 / 旋律+伴奏 / 左手贝斯+右手钢琴 / 弦乐铺底），学习项目中禁用。
- 节拍器/预备拍：`♩ 节拍器` 按项目速度走拍（CLICK 通道，重拍 96 / 弱拍 84）；
  `预备拍` 开启后录音先空一小节，只响节拍、不记录；停止录音时若节拍器按钮
  未开则一并停止。
- 音色叠加/键盘分区：每轨「叠」一键叠加第二音色（钢琴优先叠弦乐，反之叠电钢），
  试听走通道 13；「分」按当前映射第 17 键为界，低区贝斯、高区本轨音色，
  试听走左右通道 11/12，光条上画红色分区线；叠加与分区互斥。
  回放/MIDI 导出会为叠加或分区生成独立声部（通道 1–8、10–15，跳过鼓通道 9）。
- 量化与录音标记：卷帘工具栏「量化 1/8」把当前轨起点对齐到 0.5 拍；
  录音时开预备拍/节拍器会记录到项目，供阶段 7 步骤检查。
- 尚未做：项目浏览器/重命名。
  损坏但存在的项目文件会按容错载入为空项目；保存/载入前会先收尾当前录音。

串口、音频、渲染都不在 UI 线程；所有状态经 Qt signal/slot 回到主线程。
电脑键盘事件通过 `MainWindow.eventFilter` 进入同一个 Instrument，不另做时序；
键位设置页复用同一个 `KeyBindings` 对象，改绑后事件过滤器立即生效。
