## 这次设计的四条主线

1. **底部光条**：32 条等宽半透明扁条；无钢琴键图形、无木框；按下才出现彩色光柱，
   520–700 ms 消失；浮层不占布局；鼠标点键发声移除。→ UI §5
2. **中文 + 键位**：所有功能按钮中文；术语有解释；演奏键位 + 功能键位均可重绑；
   琴与电脑键盘统一为 InputHub；不碰鼠标可以演奏/练习/录音/翻页。→ UI §6–§8
3. **内置教学**：9 阶段：上手 → 五线谱 → 节奏 → 右手 → 左手/和弦 → 双手+伴奏 →
   表现 → 录音/编曲 → 多乐器合成；每阶段有指导书、训练、曲目、通关。
   **核心 59 曲 + 62 谱面训练 100% MusicXML/MIDI**；54 条生成训练有 JSON 规格；
   未就绪内容不进入学习路径。→ UI §9–§12 + CURRICULUM + CONTENT_PIPELINE
4. **整合与简洁**：6 个一级入口（演奏/学习/曲谱/创作/设备/设置）；
   **本阶段新增第 7 个“帮助”**；简单模式默认；
   首次向导 5 分钟；阶段路线图 + 用户选曲；光条让出主空间给谱面/指导。→ UI §3–§4、§10
5. **私有/公开版**：个人使用可直接收；每个内容标 visibility/public_release；
   公开版自动剔除/替换不可公开内容。→ RELEASE_POLICY

## 评审结论（2026-11-01）

用一次性原型对比了三种光条结构（A 规范 / B 手区分组 / C 演出幕布），用户实测后定：

1. **光条：C 演出幕布。** 连成一条半透明幕布、无钢琴几何、只在按下时出现彩色
   光柱和浮出音名；功能胶囊缩在右上角。按反馈把幕布压扁：总高 **52 px**、
   槽高 **32 px**（原提案 64/44）。已实现于 `pc/app/ui/light_bar.py`。
2. **键位：三行顺序通过。** `Z X C V … / A S D … / Q W E …` 与实体琴合并进
   InputHub；功能键改为 Ctrl 组合，字母全部留给音符；`Tab` 焦点遍历，
   `Ctrl+Tab` 显示键帽/音名。
3. **鼠标弹琴移除。** 光条点击不发声；鼠标只操作功能胶囊、页面与设置。
4. 一次性原型及其 A/B/C 切换器已删除；验证渲染保存在
   `pc/mockups/p1_5_lightbar_*.png`。
5. **中文优先与 6 个导航入口已实现**：演奏 / 学习 / 曲谱 / 创作 / 设备 / 设置；
   音色与校准收为子页；映射、音色、主题名中文优先。**第 7 个“帮助”为本阶段
   新增（规划）**，F1/顶栏入口一并改为进入帮助页。
6. **键位设置页已实现**：32 个音符键与全部功能键可改绑、冲突提示替换、
   自动保存 JSON、导入/导出、恢复默认。左右分区已实现（见「宽音域左右
   分区」）；白键简化预设尚未做。

## P2 纵向切片（2026-11-02）

已实现一条从可解析谱到跟弹的完整路径：

1. **解析**：`core/score.py` 用标准库解析 MusicXML（所有 part；divisions/
   time/key/tempo；音符/休止/和弦/backup/forward）与 MIDI（format 0/1、PPQ、
   note on/off、set_tempo、拍号）。不引入 music21/mido。
2. **样曲**：`pc/resources/scores/xiaoxingxing.musicxml` / `.mid`，公有领域，
   由 `pc/tools/make_sample_score.py` 生成；MusicXML 与 MIDI 解析结果一致。
3. **落键视图**：`score_view.py` 画真实音符、拍/小节网格、播放头、当前/下一音；
   自动滚动；`落键` 视图与 `谱面` 自绘谱表都可用（H7a）。
4. **跟弹**：`core/follow.py` 以“物理光条”判定（不是绝对 MIDI），所以八度/
   移调后仍可按高亮键跟弹；按对推进，按错计数并让目标光条闪红；`重来` 归零。
5. **示范**：`Space` 播放/暂停；播放头、自动滚动、光条光柱与声音跟随；
   示范不参与判定；`Esc` 停止示范。
6. **自动跟随**：右栏开关按小节/乐句把曲子切成最多 4 小节一段的窗口，段内
   选一个八度；只在段边界换窗，段内手动八度保留。整曲一个窗口时只显示音域。
7. **换谱**：拖入 `.musicxml/.mxl/.xml/.mid/.midi`；解析失败给中文提示。
8. **未做**：五线谱高级排版（连音线/多声部/完整符号/分页）、
   反复段展开、按曲目自动套用分区、
   OMR、SMPTE MIDI。（同一 onset 的和弦/双手判定与内置左右分区已做。）

## P3 纵向切片（2026-11-02）

学习页按一次原型评审选定 **C 结构**，并按用户反馈做了两处关键调整：

1. **首屏是全貌，不是左右分栏**：基础 / 演奏 / 创作三组、9 个阶段一次可见；
   每张卡显示状态、就绪数量、进度条。点阶段才替换为整页阶段内容。
   从左侧进入「学习」始终先到全貌；只有从实操点「返回学习」才回到原
   阶段 / 指导书。
2. **上次位置**：`core/progress.py` 把上次阶段 / 项目 / 指导书写进本地
   `learning.json`；顶部「继续上次」和阶段卡的「上次」标记都读它。只在真正
   打开阶段 / 指导书 / 练习后创建文件，不使用学习功能就不会产生文件。
3. **指导书整页**：阶段页的三张指导书卡点开是整页课程视图（目标 / 要点 /
   去练习）；正文与图示仍标“制作中”。
4. **学习 ↔ 演奏的契约**（实现于 `main_window.py`）：
   - 训练 / 曲目标「去练习」时，按内容里的 `score` 自动载入 MusicXML/MIDI；
   - 学习会话期间顶栏显示「← 返回学习」，**所有页面可见**（工具提示带
     阶段 / 项目），返回后恢复原阶段页或指导书；
   - 左侧导航在会话内可自由切换演奏 / 曲谱 / 创作 / 设备；拖入新谱、
     点「学习」导航或点返回按钮才结束会话；
   - 不使用学习功能时，顶栏没有返回按钮，演奏 / 曲谱 / 创作行为与之前一致。
5. **练习结果与完成**：返回学习时把本次命中 / 未中 / 总数写进
   `learning.json`（每项保留最佳成绩，差的重跑不覆盖）；阶段页/指导书显示
   最佳成绩；所有**可练习**项目完成后阶段卡显示“✓ 可练内容完成”，只有
   全部内容都就绪时才显示“✓ 已完成”。只听示范、没有按键离开不记录。
6. **内容诚实**：只有真实存在可解析谱或已实现生成器的训练/曲目可练习
   （当前阶段 0 的「跟弹《小星星》第一句」、阶段 1 的五条识谱训练、
   阶段 2 的七条节奏训练（含休止/附点、6/8、切分、三连音）、阶段 3 的「五指位置 · C–G」与
   「小星星（片段）」）；
   其余显示“制作中”，不伪装成可跟弹。
7. **识谱训练（P3 识谱切片）**：阶段 1 的四条生成式训练已可练：
   「音名闪卡 · C4–C5」、「线间定位 · 高音谱号」（C4–C6）、「八度上下行」
   （C/E/G/A 跨 C4–G6）、「临时记号 · 升与降」（♯/♭）。`core/drill.py` 负责
   题组、精确 MIDI 判定、首次答对/首答反应/连对统计；`NotePrompt` 保留题目
   拼写（B♭4 画在 B 线），MIDI 决定答案，32 键仍用升号标注，反馈会注明
   「键面 A#4」这类等音。`ui/drill_page.py` 画高音谱号单音题、加线与升降号，
   以及 32 槽作答条。答错保留题目、标出正确槽并允许重试；10 题完成后写入
   最佳成绩。训练期间临时映射 C4–G6，映射/八度/移调锁定，退出恢复；不进入
   演奏页，也不影响普通演奏。当前完成条件是“10 题全部解出”，80% 首次答对
   是推荐目标；H7d 的可选「阶段 1 考核 · 20 音」独立承载 20 题/80%，
   不改变普通练习完成条件；低音谱号、双音/和弦仍是后续内容。
8. **节奏训练（P3 节奏切片 + P2-H1）**：阶段 2 的七条生成式训练已可练：
   4/4 四分/二分、4/4 八分、3/4 圆舞曲、**休止与附点**、**6/8 复拍子**、
   **切分节奏**、**三连音**。`core/rhythm.py`
   负责节奏型、1 小节预备拍、逐拍节拍器调度与 ±100–150 ms 踩拍判定；
   `rest(beats)` 用负时值标记休止，`note_events` 只把音符计入总数/漏拍/多按，
   休止块不会被判漏；附点用 1.5/3.0 拍表示。`ui/rhythm_view.py` 画小节/拍点/
   时值块/休止块/播放头（休止为虚线「休」，附点标 `1·`/`½·`/`3`）。任意键
   作答，不改变音域映射；完成/退出写 `learning.json`（踩准、漏拍+多按、
   平均偏差、最长连对）。当前完成条件是“所有 onset 至少踩准一次”；H7d 的
   可选「阶段 2 考核」以 60 BPM、16 拍全中、无漏拍/多按、平均偏差 <60 ms
