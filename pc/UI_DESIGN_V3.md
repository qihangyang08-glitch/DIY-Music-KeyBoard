## 0. 摘要：这次改什么

v3 是一次产品形态升级，不是换皮。四条主线：

1. **底部不再画钢琴**：32 个半透明扁条，只做输入指示与瞬时彩色特效；
   鼠标点击琴键发声的功能移除。演奏输入只来自实体琴和电脑键盘。
2. **中文优先 + 全键位可绑**：所有功能按钮中文化（英文只做术语备注），
   新增"键位设置"，把电脑键盘变成第二台硬件操作器；演奏和练习可以完全不碰鼠标。
3. **内置完整教学**：五线谱、识谱、节奏、单手、双手 + 伴奏、录音回放、
   多乐器合成，形成一条从零基础到作品创作的路径。
4. **一个入口，三层深度**：默认"简单模式"，只出现演奏/学习/曲谱/创作和必要控制；
   需要时展开高级功能。用户选阶段 → 看指导书 → 选训练/曲目 → 练习 → 得到反馈。

### 0.1 需求对照表

| 你的要求 | 本设计的响应 | 章节 |
|---|---|---|
| 底部改成半透明扁条；只在按下时发彩色特效；特效发完消失、不占主空间；移除鼠标点键发声 | 32 槽 Light Bar + 浮层特效；固定 64 px；无琴键图形；鼠标仅悬停显示信息，不发声 | §5、§9 |
| 功能按钮中文化；有中文解释；支持绑定电脑键盘，琴与电脑键盘统一为操作器 | 中文文案与术语表；InputHub 统一输入；演奏键位 + 功能键位两套绑定；冲突检测 | §7、§8 |
| 全套教学：五线谱、识谱与实操、进阶合成；网上找教程/曲目；内置资源；配合解析谱、按键指示、自动功能与合成 | 9 阶段课程、116 训练、67 曲目/项目；**核心 59 曲 + 62 谱面训练 100% MusicXML/MIDI**；54 生成训练 JSON；学习/练习/曲库/创作；资源与许可 | §9–§13、Curriculum、ContentPipeline |

### 0.2 明确不做

- 不做鼠标弹琴；不做鼠标划过发光；32 条只响应实体琴和电脑键盘。
- 不做力度曲线。传感器对距离远比对压力敏感，继续固定 velocity，用时长、连奏、延音表达。
- 不做完整 DAW、VST 宿主、音频录音、云账号、社交、手机版。
- 公开版不打包版权不明/不可再分发的曲谱、录音、教材或歌词；
  私有版可含个人使用内容，但必须标 `visibility/public_release`，公开版剔除/替换。
- 核心课程不以 PDF/图片作为主谱面；必须有 MusicXML/MIDI 或生成式 JSON 规格，
  否则无法跟谱/下一键/判定。

### 0.3 现有功能去向（v2.1 → v3）

| v2.1 功能 | v3 位置 | 变化 |
|---|---|---|
| 32 键钢琴键盘 + 木框 | 底部 32 条光条 | 不画琴键/木框；鼠标不发声；特效浮层 |
| 顶部 32 键引导条 | 顶部 32 格提示带 | 不画琴键；只做下一键/按下提示 |
| 4 个 pad | 光条右侧 4 个功能胶囊 | 功能不变；可改用途；可绑键盘 |
| 音色 / 映射 / 八度 / 移调 / 录音 / Panic | 右栏 + 设置 | 中文化；录音在 P5 变成真录音；Panic → 全部静音 |
| 曲谱页（谱面/落键/专注/缩放） | 演奏页 + 练习页 | 增加跟谱/下一键/伴奏/循环/速度 |
| 左栏 6 项 | 演奏/学习/曲谱/创作/设备/设置 | 新增学习/创作；音色收进上下文；校准进设备 |
| Studio / Stage 主题 | 设置 | 纸白/暗场中文名；光效仍彩色，可切单色 |
| 快捷键（M/P/C/F 等） | 键位设置 | 默认改为不冲突布局；全部可重绑 |
| 串口自动检测 / 20 ms / NoteEngine | InputHub + 现有引擎 | 协议不变；新增电脑键盘统一输入 |
| profile / 校准 | 方案 / 设备 | 校准仍 P3；profile 明确为"方案/档案" |
| FluidSynth + SoundFont | 演奏 + 创作 | 48 kHz；静音用 CC7；多轨/音色分层 |

**不变的部分**：20 ms 轮询、固定 velocity、FluidSynth 48 kHz、串口状态行、
32 键 + 4 功能键的硬件通道、NoteEngine 的边沿/和弦/滑音/延音语义。

## 1. 用户与使用场景

### 1.1 用户画像

| 画像 | 特征 | 设计重点 |
|---|---|---|
| 零基础自学者 | 不认识五线谱，没用过 DAW，英文按钮有压力；有 32 键琴，也可能暂时没接硬件 | 中文、首次向导、键位图、第一课、明确下一步 |
| 有基础的业余演奏者 | 能看简单谱，想跟谱练习、分手/双手、录音 | 曲谱库、练习模式、伴奏、速度/循环 |
| 兴趣创作者 | 想录多轨、换音色、做一段完整音乐 | 创作页、分层/分区、导出 MIDI |

### 1.2 典型场景

1. **第一次打开**：不知道从哪开始 → 5 分钟向导 → 发出第一个音 → 完成"第一课"。
2. **每天练习**：打开软件 → "继续上次" → 按指导书练 2 小节 → 慢速循环 → 跟弹 → 记录。
3. **学一首曲子**：阶段页 → 选曲目 → 看指导书 → 右手 → 左手 → 合手 → 完整演奏。
4. **自由演奏**：演奏页 → 选音色/音域 → 直接用琴或电脑键盘弹。
5. **做作品**：创作页 → 录一条旋律 → 加伴奏轨 → 换音色 → 分轨导出。

### 1.3 产品约束

- 32 个物理键，音域通过映射变化；不是 88 键钢琴。
- 没有力度；按键只有按下/松开与时长。
- 输入有约 20 ms 轮询；可以练习，但极快的装饰音会受限。
- 琴的 4 个剩余键（通道 33–36）是功能键，不是音符。
- 用户可能没有硬件；电脑键盘必须能独立完成全部演奏与练习。

## 2. 设计原则

1. **中文优先**：所有可见按钮、标题、提示用中文；英文只出现在括号、术语表或高级设置里。
2. **零鼠标演奏**：演奏、练习、翻谱、录音、节拍器、切换音色都能用电脑键盘完成；鼠标只用于浏览和编辑。
3. **一次只教一件事**：简单模式隐藏高级参数；新手只看到"下一步做什么"。
4. **默认自动化，开关可见**：自动跟随、自动滚动、下一键、自动音域映射默认开；每个自动行为都有明确开关。
5. **学习闭环**：目标 → 知识 → 示范 → 练习 → 反馈 → 下一步；每个阶段都有指导书，不是只给曲谱。
6. **特效不占空间**：光条固定 64 px；彩色光柱是浮层，消失后不留痕迹、不改变布局。
7. **不假装**：没有校准就写"未校准"；没有力度就不做力度曲线；不把图片谱伪装成可跟随谱。
8. **可访问**：不依赖颜色传达唯一信息；支持减少动效、字号、键盘导航、色盲友好配色。
9. **内容可替换**：课程、曲目、键位、音色、界面文案都走数据/资源，不在代码里写死。

## 3. 信息架构与导航

### 3.1 七个一级入口（第 7 个“帮助”为本阶段新增）

```
演奏   学习   曲谱   创作   设备   设置   帮助
```

| 入口 | 作用 | 主要内容 |
|---|---|---|
| **演奏** | 打开就弹 | 谱面/落键、音色、音域映射、八度/移调、录音、全部静音、光条 |
| **学习** | 从零到作品 | 9 阶段路线图、指导书、训练、曲目、练习、进度 |
| **曲谱** | 找谱、导入 | 内置曲库、筛选、导入 MusicXML/MIDI/图片、曲目详情 |
| **创作** | 录音、编曲、合成 | 多轨录音、叠录、音色、分层/分区、钢琴卷帘、混音、导出 |
| **设备** | 硬件与校准 | 3 模块状态、通道表、4 个功能键、**逐键阈值校准**、诊断 |
| **设置** | 个性化 | 键位、主题、语言、字号、音频、练习偏好、数据导入导出 |
| **帮助** | 页面/按钮怎么用 | 快速开始、页面地图、按钮说明、故障排查、重开首启向导 |

**音色**不单独占一级入口：它出现在演奏页右栏和创作页的音轨设置里。
**校准**收进设备页，但校准页本身是完整工作页（不再用说明占位）。
**当前代码仍是 6 个入口**；第 7 个“帮助”在 A3 切片实现，快捷键
`Ctrl+7`，F1 与顶栏“怎么用”也进入该页。

### 3.2 顶部常驻栏

```
KEYBORAD  32 键电子琴    ●●● 3 个模块在线   音域映射 · 半音阶 · F4–C7   方案 · 裸铜    怎么用   48 kHz   🔊   ⚙
```

- 左：品牌 + 设备灯 + "3 个模块在线"（中文；英文 "3 modules" 只在高级提示里）。
- 中：当前音域映射（点击打开映射面板）；当前方案。
- 右：帮助"怎么用"（F1）、音量/静音、设置。
- 帮助按钮始终可见，是新手的第一入口。

### 3.3 简单模式 / 高级模式

- **简单模式（默认）**：演奏页只显示音色、音域映射（只读入口）、八度、录音、
  全部静音、光条；自动跟随、移调、高级参数收进"更多"。
  学习页突出当前阶段与"继续"，其余阶段折叠成一行；设备页折叠成"设备正常/有问题"。
- **高级模式**：显示音域映射细节、自动跟随、移调、release grace、legato、
  固定 velocity、校准阈值、键位冲突、日志、固件信息。
- 切换在设置里，一次点击；高级模式不会打乱简单模式的布局，只是多出卡片。

## 4. 全局布局与尺度

### 4.1 基准画布

- 设计基准：1440 × 900（与 v2 一致）。
- 最小窗口：1120 × 760。
- 高 DPI 自适应；所有自定义绘制用逻辑像素。
- 内容区左右留白 18 px；面板间距 12 px；圆角：面板 20 px、卡片 14 px、光条 6 px。

## 5. 底部光条演奏带（核心新组件）

### 5.1 它是什么，不是什么

- 是：32 个等宽的半透明输入指示槽，从左到右对应物理键 1–32；
  用于显示按下、下一键、左右手、电脑键位；是演奏和练习的唯一可视化输入面。
- 不是：钢琴键盘。没有白键/黑键分组，没有琴键轮廓，没有木框，不显示完整音阶刻度。
- 不是：鼠标乐器。鼠标悬停只显示信息，点击不发声、不产生光柱、不切换音符。

### 5.2 几何与视觉

> **实现备注（2026-11-01）：** 评审选定 C 演出幕布，并在真实窗口中把幕布压扁为
> **总高 52 px / 槽高 32 px**（上方 20 px 放浮出音名与功能胶囊）；下表 64/44
> 保留为原始提案。实现见 `pc/app/ui/light_bar.py`。

| 项 | 规格 |
|---|---|
| 槽数 | 32（与物理键 1–32 一一对应） |
| 总高 | 64 px（上下各 10 px 呼吸区） |
| 槽高 | 44 px |
| 槽宽 | (光条可用宽度 − 31 × 4 px 间距) ÷ 32；光条可用宽度 = 总宽 − 右侧 4 个功能键；1120 宽窗口约 27–29 px |
| 圆角 | 6 px |
| 静息填充 | Studio：白色 8% 叠在纸面；Stage：白色 6% |
| 静息描边 | 1 px，`hair` 色（Studio 近黑 8%，Stage 白 10%） |
| 分组 | 不加黑白键分组；可选一条 1 px 左右手分隔线 |
| 标签 | 默认不显示；首次使用/学习模式默认显示音名/电脑键位，熟练后可关 |
| 鼠标 | 悬停显示 tooltip：`键 8 · C5 · 电脑键 D · 右手`；点击无动作 |

**为什么等宽而不是钢琴布局**：32 个电容键本身就是等距的物理条；用户要的是"按哪条、
发出什么音、有什么反馈"，不是复制一台钢琴。等宽槽让物理键号、电脑键位、音名三者
可以放在同一个位置，学习成本最低。

### 5.3 状态

| 状态 | 表现 |
|---|---|
| 静息 | 半透明扁条；无音名；无光柱 |
| 悬停 | 槽背景 +2% 亮度；显示 tooltip；**不发声** |
| 按下 | 槽内填充特效色 18%；1 px 彩色描边；底部起光柱 |
| 按住 | 槽保持按下色与描边；光柱首帧结束后只留柔和底色，不持续占空间 |
| 松开 | 槽在 160 ms 内回到静息；光柱在 520–700 ms 内渐隐 |
| 下一键提示 | 2 px 暖金/左右手色描边缓慢呼吸（1.2 s）；不填充；不闪屏 |
| 未映射 | 槽变暗 40%，tooltip 说明"此键当前无音" |
| 禁用（非演奏页） | 整条变暗，不响应输入；显示"回到演奏页开始" |

> **P3 识谱训练例外：** 学习页的识谱训练使用独立的 32 槽作答条，不是演奏
> 光条。它仍遵守“点击不发声”，只显示当前映射、键位、音名和答对/答错反馈；
> 输入来自实体琴或电脑键盘。训练期间映射锁定为 C4–G6，退出恢复。

### 5.4 彩色特效

按下时：

1. **槽内 bloom**：从槽底向上扩散的柔光，宽约槽宽 80%，300 ms。
2. **上升光柱**：宽约槽宽 70%，高 100–150 px，三层叠加（外层宽而淡、内层窄而亮），
   向上没入主内容区域，520–700 ms 渐隐；不改变布局。
3. **可选微粒**：最多 6 个/次；默认关；减少动效时禁用。
4. **和弦**：每个按下键各自一条，最多 24 条并发；超出时合并为槽内光。
5. **滑音**：新键按下时旧柱继续按自己的时间淡出，不追赶、不拖尾。

颜色模式（设置 → 主题 → 光效）：

| 模式 | 规则 | 适用 |
|---|---|---|
| **音高彩虹（默认）** | 12 个音高类各有一个色相；八度用亮度区分 | 想看到"音高在哪" |
| **左右手** | 左手青绿 `#3E8E8A`，右手暖金 `#D8A24A` | 双手练习、分区 |
| **单色** | Studio 暖金、Stage 冰白 | 演出、低干扰 |

- 颜色不是唯一信息：学习模式始终有音名/左右手文字；色盲模式切换为蓝-橙双色。
- Stage 主题保留彩色光效；需要"冰白"时用单色模式，不再强制全白。
- 减少动效：只保留槽内 bloom，无上升光柱；仍然有按下反馈。

### 5.5 左右手与分区

- 默认不分区；学习模式按曲目设置显示左手/右手色。
- **已实现（2026-11-08）**：内置「左右分区」音域映射，分界 bar 16；左区
  C3–D#4、右区 C5–D#6（中间 E4–B4 不可达）。范围显示两段，光条在分界画
  1 px 细线；跟弹与自动跟随都按两区整体判定。
- **已实现（2026-11-09，H7f）**：学习条目可声明映射预设或结构化映射；
  「左右分区 · 8 小节」从学习页或曲库打开时自动套用并把八度/移调归零，
  退出、换谱或打开项目时恢复用户原来的映射。练习中仍可临时改，退出时丢弃；
  曲库按文件 stem 反查课程声明。
- **已实现（2026-11-09）**：新增「白键 19 键」音域映射（C4–G6 白键 →
  键 1–19，20–32 禁用；禁用槽画暗、显示“—”、按键不发声）。光条上的
  琥珀分区线加粗并带握把，可拖动（1–31），右栏显示「分区 N · 拖动光条
  琥珀线调整」+「重置」，松手按曲目保存并在下次打开时恢复，重置清除保存值
  并回到内容默认分区。光条静息时黑键槽位使用明显暗色渐变与顶部小点作为
  方位提示；槽位仍等宽，不画钢琴键轮廓。
- 分区可设在任意槽；默认建议 16/16（1–16 左手，17–32 右手）。
- 分区线是 1 px 细线，不是琴键；两侧槽的静息色可以各带 2% 的冷暖差。
- 分区的音域与音符由"音域映射"决定，不由槽的左右位置决定。

### 5.6 4 个功能键（物理通道 33–36）

光条右侧固定 4 个小胶囊，和光条同高，保持半透明：

```
[ 延音 ] [ 八度− ] [ 八度+ ] [ 映射 ]
```

- 延音：按住有效；设置可选"点按锁定/解锁"。
- 八度−/+：单击移八度；长按连续？不做连续，避免误触。
- 映射：短按循环音域映射；长按切换"自动跟随"（1 秒长按，带进度环）。
- 这些是**功能键**，不是音符；允许鼠标点击（只触发功能，不产生音符，不违反"鼠标不弹琴"）。
- 若用户想要完全零鼠标，可用硬件功能键或电脑键盘绑定，鼠标按钮可忽略。
- 每个功能键可在设置里改用途：播放/暂停、上一首/下一首、节拍器、录音、翻页等。
- 电脑键盘有等价功能键，见 §8。

### 5.7 顶部 32 格提示带

- 高 28–32 px，32 个细分格，等宽；不画钢琴黑白键。
- 显示：下一键、当前按下、左右手、当前映射范围。
- 图片谱 / 无跟随时：左侧显示"无跟随 · 手动翻页"，格子只反映按下。
- 点击不发声；只作为提示。若与底部光条重复，可在设置里隐藏。

### 5.8 性能与实现约束（设计级）

- 光柱层是浮层：`WA_TransparentForMouseEvents`，绘制在主内容底部上方，
  不占布局、不阻塞谱面滚动/点击。
- 30–60 fps；最多 24 条；先算好渐变，不在每帧新建大量对象。
- 窗口缩放时只重算槽宽；不重建控件。
- 关闭光效或减少动效时，不启动浮层定时器。

### 6.3 术语解释示例（按钮 tooltip）

- **音域映射**：决定这 32 条键现在分别发出哪些音。换映射不会改变你按的键，
  只会改变音高。按 `Ctrl+M` 也可以切换。
- **自动跟随**：有可解析曲谱时，软件根据谱子自动换音域；图片谱不支持。
- **移调**：整体升高/降低半音，音名跟着变；不是换调式。
- **延音**：按住时松开的音继续响；和钢琴右踏板类似。
- **全部静音**：立刻停掉所有正在响的音；不会改变你按住的键，松开再按才会重新响。
- **固定力度**：这台琴没有力度传感器，所有音一样响；强弱靠时长、连奏、延音表达。

## 7. 键位系统：琴 + 电脑键盘 = 两台统一的操作器

### 7.1 目标

- 不碰鼠标就能完成：演奏、换音色、换音域、八度/移调、录音、播放、循环、
  节拍器、翻页、进入学习/曲谱/创作/设置。
- 实体琴与电脑键盘是**同级输入源**，不是"没硬件时的替代品"。
- 每个功能都能重绑；每个音符键都能重绑；冲突可见、可解决。
- 输入法/键盘布局不改变物理键位逻辑；显示用的键帽可以随布局变。

### 7.2 输入模型（InputHub）

```
实体琴串口 ─┐
电脑键盘   ─┼─→ InputHub ─→ 统一控制事件 ─→ NoteEngine / 功能动作 / 光条 / 练习判定
4 个物理键 ─┘
（可选 MIDI 键盘，后续）
```

- 事件类型：`note_on(bar, source)`、`note_off(bar, source)`、`function(action, phase)`。
- 来源标记：`instrument` / `keyboard` / `pad`；状态栏可显示"琴"或"电脑键盘"。
- 合并规则：同一 bar 多来源按下时保持发声，直到所有来源都松开；避免一个来源松开就断音。
- 电脑键盘按下立即进入同一个 20 ms 引擎节拍；不做第二套时序。
- 忽略系统按键重复；只有真正的 key-down/key-up。按住型功能（延音）例外。
- **允许混合演奏**：例如左手按电脑键盘、右手弹实体琴，两个来源合并到同一个
  NoteEngine；同一个 bar 被两个来源按住时，直到两边都松开才停音。
- 状态栏显示当前来源（"琴" / "电脑键盘" / "两者"），方便排查"为什么有音/没音"。

### 7.3 默认演奏键位（32 键）

采用三行、从左到右、从低到高的顺序布局：

| 光条 | 1–10 | 11–21 | 22–32 |
|---|---|---|---|
| 电脑键（US 键帽） | `Z X C V B N M , . /` | `A S D F G H J K L ; '` | `Q W E R T Y U I O P [` |
| 默认手区 | 左手 1–10 | 左手 11–16 / 右手 17–21 | 右手 22–32 |

- 共 10 + 11 + 11 = 32。
- 物理键码绑定，不按字符绑定；中文输入法开启时仍按物理位置工作（见 §7.8）。
- 光条辅助显示时，槽上角显示键帽，下角显示音名；默认隐藏。
- 60% / 无 `; ' [` 的键盘：允许把未绑定槽映射到其他键；设置页显示"已绑定 29/32"。

可选预设：

| 预设 | 适用 | 说明 |
|---|---|---|
| **三行顺序（默认）** | 大多数用户 | 从上表；最好记 |
| **左右分区** | 双手练习 | 左手 1–16 集中在键盘左半，右手 17–32 在右半；软件生成键位图，可微调 |
| **白键简化** | 只弹 C 大调 | 19 个白键音映射到 19 个键；其余槽禁用；适合识谱入门 |
| **自定义** | 进阶 | 任意重绑；导入/导出 |

| 全屏 | `F11` | |
| 列表/小节导航 | 方向键 | 不发声；输入框聚焦时除外 |

新手不需要在"弹琴"和"快捷键"之间记两套字母。所有功能仍可重绑。

**键名说明**：`Space`/`Ctrl`/`Shift`/`Esc` 等是键盘上的物理键名，保留英文；
动作说明一律中文。设置页显示为"空格键（Space）""Esc（全部静音）"等，
不让新手只看到英文缩写。

  注明等音）。首次答对、首答平均反应、最长连对、准确率写入 `learning.json`；
  答错保留题目并显示正确槽，不阻止完成。80% 首次答对是推荐目标；H7d 另提供
  可选「阶段 1 考核 · 20 音」，首答 ≥16 通过，成绩独立保存，不阻止普通
  练习完成。低音谱号已完成（阶段 4「低音谱号 · C3–C4」）；
  双音/和弦识谱级别仍未做。

### 9.6 节奏训练

- 显示节奏型；用户按任意键/拍手（电脑键盘也可以）跟节拍器。
- 判定：拍点偏差、漏拍、多拍；用颜色/文字反馈，不用红叉。
- 级别：四分/二分 → 八分 → 附点/切分 → 6/8。
- 可把节奏型直接变成一段单音练习，接到光条上。
- **已实现（2026-11-02）：** 4/4 四分/二分、4/4 八分、3/4 圆舞曲三条；
  1 小节预备拍、80 BPM 逐拍节拍器（独立通道，不切用户音）、任意键踩拍、
  ±100–150 ms 窗口、漏拍/多按/平均偏差/连对写入 `learning.json`。
  休止与附点已完成（虚线「休」块；附点标 `1·`/`½·`/`3`，休止不计入总数/
  漏拍，休止处按键记多按）。**P2-H1（2026-11-10）补齐 6/8、切分与三连音**：
  6/8 重拍在第 1/4 拍（`accent_beats`），页面按 `meter_label` 显示拍号；
  “节奏型转单音”仍未做。
  H7d 另提供可选「阶段 2 考核」：4/4 · 4 小节 · 60 BPM，16 拍全部踩准、
  无漏拍/多按且平均偏差 <60 ms 通过，成绩独立保存，不影响普通练习。

### 9.7 曲目练习流程

1. 看指导书（这首曲子练什么）。
2. 听示范（自动演奏 + 光条）。
3. 慢速分手（50%）。
4. 循环困难小节。
5. 合手/加伴奏。
6. 原速完整弹。
7. 录音回放，自评。
8. 标记"完成"或"再练"。

### 9.8 进度

- 本地学习档案：阶段/课程/训练/曲目的状态、最佳速度、准确率、练习时长、最近练习。
- "继续上次"回到上次的曲目/小节/速度。
- 不强制按顺序解锁：所有阶段可看；推荐顺序高亮。
- 可导出/导入学习档案；不上传云端。

## 11. 练习模式（完整交互）

### 11.1 模式矩阵

| 模式 | 判定 | 伴奏 | 适合 |
|---|---|---|---|
| 识谱 | 音名/位置 | 无 | 阶段 1 |
| 节奏 | 拍点 | 节拍器 | 阶段 2 |
| 分手 | 单手音符 | 另一手自动 | 阶段 3–5 |
| 双手 | 双手音符 | 无/轻伴奏 | 阶段 5–6 |
| 跟弹 | 等待正确音 | 可选 | 阶段 3–6 |
| 伴奏 | 只判旋律 | 自动伴奏 | 阶段 5 |
| 循环 | 小节/选区 | 可选 | 所有阶段 |
| 慢速 | 50–100% | 可选 | 所有阶段 |
| 录音回放 | 不判定 | 可选 | 阶段 5–7 |

### 11.2 判定与反馈

- 输入：`NoteEngine` 的 note_on/off + 时间戳；映射后的 MIDI 音高。
- 期望：曲谱时间线上的音高/时值；按拍点匹配。
- 指标：
  - 音符正确率 = 正确音 / 期望音。
  - 多音 = 未在谱上的音；漏音 = 未弹的期望音。
  - 节奏稳定度 = 与拍点的平均偏差（毫秒）与波动。
  - 完成度 = 已通过的小节/总小节。
- 反馈颜色：正确 = 暖金/白；偏差 = 琥珀；错误 = 砖红；
  同时给文字（"第 3 小节左手晚了 80 ms"），不只靠颜色。
- 通过标准由课程定义（如"正确率 ≥ 90%，速度 ≥ 80%，无漏音"）；
  用户可切"宽松/严格"；默认宽松。

### 11.3 伴奏与双手

- 曲目元数据标明左手/右手声部；练习页可选：
  - 我弹右手，软件弹左手；
  - 我弹左手，软件弹右手；
  - 我弹双手，软件只给节拍/轻伴奏。
- 伴奏由曲谱生成（FluidSynth），不是预录；可调音量/音色。
- 跟弹模式下，软件等待你弹对再走；伴奏模式不等待，保持节奏。
- 这是"从单手到双手"的关键桥梁：先右手 + 自动左手，再互换，最后双手。

> **已实现（2026-11-09，H7e）：** 学习内容用 `PracticeItem.accompaniment`
> 声明一个 MusicXML part；阶段 5 的「小星星」「欢乐颂」「两只老虎」三首
> “自动左手”实现“我弹右手，软件弹左手”，伴奏在独立通道自动演奏，不参与
> 判定。当前实现属于括弧中的“跟弹模式 + 可选伴奏”：软件等你弹对再走，按键
> 即节拍；尚未实现独立的不等待伴奏模式、左右手互换选项与可调伴奏音量/音色。

### 11.4 录音回放

- 录制音符事件（时间、音高、时长、音色），不录麦克风音频。
- 回放：原速/慢速；可循环；可显示落键。
- 对比：本次 vs 上次的准确率/速度；不做排名。
- 保存到学习档案；可导出 MIDI（阶段 7 教）。

## 12. 创作 / 多乐器合成

### 12.1 定位

不是完整 DAW；是"用 32 键琴把想法录下来、叠几轨、换音色、导出"的轻量工作台。
最多 8 轨；MIDI 事件 + 内置 FluidSynth；不做音频录音/VST。

### 12.2 页面结构

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 创作    项目：我的第一首                 [保存] [导出 MIDI] [播放/停止]      │
├──────────────────────────────────────────────────────────────────────────────┤
│ 音轨 1  钢琴 1     ▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮  音量 ─●──  声像 ─●─  [M] [S] [● 录音]│
│ 音轨 2  弦乐      ▮▮▮▮▮▮▮▮▮▮            音量 ─●──  声像 ─●─  [M] [S] [● 录音]│
│ 音轨 3  + 新增音轨                                                           │
├──────────────────────────────────────────────────────────────────────────────┤
│  小节 1    2    3    4    5    6    7    8                                   │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │  钢琴卷帘：音符块、播放头、循环区、缩放                                │  │
│  │  点击/拖动编辑；音符高度=时值；不做力度                                │  │
│  └────────────────────────────────────────────────────────────────────────┘  │
├──────────────────────────────────────────────────────────────────────────────┤
│ ▶ 播放  ⏹ 停止  ↻ 循环  ♩ 节拍器  ● 录音  ✚ 叠录  [量化 1/8]  [撤销]      │
├──────────────────────────────────────────────────────────────────────────────┤
│ 32 条光条（按下录音/试听；同样不响应鼠标）                                   │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 12.3 功能

- **录音/叠录**：从光条/琴/电脑键盘录入；节拍器/预备拍；可循环叠录。
- **量化**：可选 1/4、1/8、1/16；默认关，保留人性化。
- **钢琴卷帘**：画/擦/移动/复制音符；时值可调；无力度。
- **音色**：每轨一个 GM 音色；音量/声像/混响/合唱；静音/独奏。
  本阶段把内置音色从 7 个扩到 30 个以上（萨克斯、电吉他、笛子、弦乐、
  管乐、打击乐等），按分类展示；现有前 7 项顺序与索引保持不变，
  曲目/项目里的 GM 编号保持兼容。详见 §23.4。
- **分层/分区**：
  - 音色叠加：一个键同时触发两个音色（如钢琴 + 弦乐），可调音量。
  - 键盘分区：低音区/高音区不同音色（如左手贝斯 + 右手钢琴）；
    分区点可拖；光条上显示分区线。
- **模板**：钢琴独奏、旋律 + 伴奏、左手贝斯 + 右手钢琴、弦乐铺底。
- **导出**：MIDI（首选）；项目 JSON；WAV 离线渲染放后续。
- **教学接入**：阶段 7–8 的项目模板直接从创作页打开；指导书告诉用户每一步做什么。

### 12.4 进阶音乐合成的边界

- 内置 FluidSynth 是采样合成器；提供 GM 音色、混响、合唱、增益。
- 不做振荡器/包络编辑器；如果后续要"合成器"，作为独立实验室，不阻塞主线。
- "多乐器合成"在本设计中 = 多轨 + 多音色 + 分层/分区 + 混音 + 导出，
  不是模块合成器。

| `vermilion` | `#B94A3E` | `#D0655A` | 错误/警告 |

| `card` | 白 42% | 白 5% | 卡片 |

| `bar` | 白 8% | 白 6% | 光条静息 |

**音高彩虹**：12 色相，饱和度统一、明度按主题调整；提供"色盲友好"蓝-橙替代。
不把红/绿作为唯一正确/错误提示。

### 15.3 字体

- 中文：Noto Sans SC / 思源黑体；系统无则 Microsoft YaHei UI。
- 音名/数值/时间：JetBrains Mono / Cascadia Mono / Consolas。
- 字号：正文 13–14 px；小字 11–12 px；标题 20–28 px；光条标签 8–9 px。
- 行高 1.5；中文不加字间距；避免全大写英文长句。
- 数字用等宽对齐；BPM/时间/百分比。

### 15.4 形状与动效

- 圆角：面板 20、卡片 14、按钮 10–12、光条 6。
- 阴影：轻；不用多层发光。
- 动效：界面 120–180 ms；光柱 520–700 ms；呼吸提示 1.2 s。
- 减少动效：关闭光柱/粒子/呼吸，保留颜色变化与文字。
- 不使用弹跳、炫光、闪烁。

### 15.5 图标

- 线性图标 + 中文文字；不单独用英文缩写图标。
- 图标可来自开源图标集（如 Lucide，ISC/MIT），或自绘；保留许可说明。
- 播放/暂停/录音/节拍器/循环/分手/双手/伴奏等有明确图形 + 文字。

### 15.6 无障碍

- 文字对比度 ≥ 4.5:1；大字 ≥ 3:1。
- 不依赖颜色：音名、左右手、正确/错误都有文字或形状。
- 键盘导航：焦点描边 2 px；Tab 顺序合理；Esc 退出弹层。
- 屏幕阅读器：光条、按钮、进度有可读名称；自定义绘制控件提供 accessible name。
- 字号三档；减少动效；色盲模式。
- 光条不是鼠标控件，减少误触。

## 20. 验收标准

### 20.1 需求验收

- **R1 光条**
  - 默认界面没有钢琴键图形、没有木框、没有黑白键分组。
  - 32 条等宽半透明槽，固定 64 px；窗口缩放不改变布局高度。
  - 鼠标点击/拖动光条不发声、不产生光柱；悬停只显示信息。
  - 按下后彩色光柱在 700 ms 内消失；不遮挡/改变谱面布局。
  - 最多 24 条并发；减少动效时无上升光柱。
- **R2 中文 + 键位**
  - 所有可见功能按钮为中文（品牌/术语除外）；无未解释英文。
  - 32 个音符键 + 所有功能键可重绑；冲突可见可解决；可导入导出方案。
  - 不使用鼠标可以完成：演奏、换音色/映射、录音、播放/循环、节拍器、进入四类页面。
  - 键位图可查看；输入法/键盘无冲有说明。
- **R3 教学**
  - 9 个阶段；每阶段有目标、指导书、训练、通关标准；阶段 3 起有曲目。
  - 学习路径覆盖：五线谱 → 识谱 → 单手 → 双手 + 伴奏 → 录音回放 → 多乐器合成。
  - 阶段 1–3 至少各 10 条训练；阶段 3 起至少 8 首曲目；阶段 1–2 以识谱/节奏训练为主。
  - 总计 ≥100 条训练；59 首谱面曲目 + 8 个项目；54 条生成训练。
  - **可跟谱**：核心 59 首曲目 + 62 条谱面训练 100% 有 MusicXML + MIDI 示范；
    8 个项目有 Project JSON + MIDI；54 条生成训练有结构化规格。
  - 图片/PDF 只做补充显示，不进入核心跟谱/判定；未就绪内容明确显示"制作中"。
  - 用户可选阶段、看指导、选曲目、练习、得到反馈、继续上次。
  - 内置内容有来源/许可/可见性/就绪字段；私有版可含个人用内容，公开版按清单剔除。
- **R4 整合与简洁**
  - 7 个一级入口（新增“帮助”）；简单模式默认；高级模式可展开。
  - 首次向导 ≤5 分钟；第一课能弹出 3 个音。
  - 空态/错误态都有下一步动作。
  - 私有版可含个人用内容；公开版按 `public_release` 清单剔除/替换，
    安装包内无私有文件、无私有 ID 引用；关于页可查构建类型/排除清单。

### 20.2 体验验收

- 新用户 60 秒内发出第一个音。
- 用户能在 3 次点击/按键内从首页到任意阶段/曲目。
- 练习页所有常用动作有快捷键，且可重绑。
- 在 1120×760 下无横向溢出；右栏可滚动；光条不挤压谱面。
- 减少动效/色盲模式下仍能理解按下、下一键、左右手。
- 没有"已校准/有力度"等不实状态。

## 23. 2026-11-12 新阶段设计补充（校准 / 向导 / 音色 / 曲目）

本节是当前实现工作的设计入口；详细协议与验收以

### 23.1 逐键校准页（A2）

**用户流程**：设备 → 校准 → 点「开始检测」→ 松手采集噪声底 →
实时监控全部 32 键 → 用户按下哪些键，就为哪些键各画一条信号曲线 →
按下再松开、信号回落到基线后自动停止 → 在曲线上点选一点，
取该点的信号值作为该键阈值 → 可反复微调 → 应用到设备、保存方案 →
多指验证。

**关键设计**：

- 不指定按键；可一次按多个键，每个键独立成图，解决多指齐按丢键。
- 曲线横轴为时间，纵轴为 `filtered - baseline`（0–255）；点选曲线时
  读取该点纵坐标作为阈值，也可直接拖动水平阈值线。
- 噪声底、峰值、稳定段中位数都显示；建议阈值 = 噪声 + 8 与稳定段
  55% 的较大者，并保证低于峰值 85%。
- 释放阈值默认 `touch × 0.60`，必须小于 touch；高级模式可改。
- 弱键（峰值 < 12）不自动改全局增益，只提示检查接线/提高增益。
- 校准期间不发声、不判定、不写学习记录；离开页面恢复普通演奏。
- 阈值按 `key -> module/electrode` 写入 MPR121 的 0x41/0x42；
  PC 保存 `calibration.json` 并在每次连接后重发。固件 NVS 持久化
  留到 C4。
- 固件新增 `CAL` 25 Hz 数据流与 `T` 写阈值命令；详细格式、数据预算、
  测试与人工验收见 [CALIBRATION_DESIGN.md](CALIBRATION_DESIGN.md)。
