## 1. 结论先行

1. **主教材不使用外部 PDF 作为运行时内容。** 课程文字、例子、练习、曲目全部由本项目
   以结构化 JSON + MusicXML 生产；外部教材只做参考与选题来源。
2. **所有"带谱面"的核心内容 100% 有 MusicXML + MIDI 示范。**
   不使用"只有 PDF/图片"的曲目作为主练习；图片/PDF 只能做补充展示。
3. **生成式训练不需要 MusicXML，但必须有结构化 JSON 规格**
   （题目类型、音域、节奏型、答案、判定规则）。
4. **数量目标**：完整版 59 首谱面曲目 + 62 条谱面训练 + 54 条生成训练 +
   8 个创作项目；MVP 先完成阶段 0–3（18 首曲目 + 64 条训练）。
5. **私有构建可以包含个人使用的内容；公开构建按标记自动剔除/替换。**
   详见 [RELEASE_POLICY.md](RELEASE_POLICY.md)。
6. **数量不是瓶颈**：MuseTrainer（70+ `.mxl`）、schoolbandclass（11,500+ PD 候选）、
   OpenScore（CC0）、MuseScore 公共领域、Pianovera MIDI、Beyer/Czerny 重录，
   候选池足够；但只有通过校验的内容才能进核心课程。

## 2. 什么算"可被软件读取解析"

| 内容类型 | 必需格式 | 用途 |
|---|---|---|
| 谱面曲目 | **MusicXML**（`.musicxml`/`.mxl`）+ MIDI 示范 | 渲染、播放头、下一键、自动滚动、伴奏、判定 |
| 谱面训练 | **MusicXML** + MIDI 示范 | 同上 |
| 生成式训练（识谱/节奏） | JSON 训练规格 + 生成器 | 随机题目、判定、难度 |
| 创作项目 | Project JSON + MIDI | 多轨、回放、导出 |
| 课程文字/知识卡 | Lesson JSON + Markdown 子集 | 学习页/指导书（P2-G；阶段 0–8 五十七节全部接入） |
| 图片/PDF 谱 | 仅图片 | 只显示/翻页，**不能跟随**，不作为核心练习 |

**判定标准**：

- 软件能在无人工干预下解析出：调号、拍号、小节、音符/休止、时值、连音/反复、
  声部/左右手、速度。
- 能生成：下一键序列、当前小节、播放头时间线、左右手过滤、伴奏事件。
- 能在 32 键映射下弹奏：每个音都有对应光条/键位，不越界（或明确标注）。
- 能在练习模式里判定：音高、时值、漏音/多音、节拍。

只满足"能显示 PDF"不算可解析；只满足"能播放 MIDI"也不够——还必须有谱面/音符
结构来支持下一键与判定。

## 4. 教材与曲目来源策略

### 4.1 分层

| 层 | 内容 | 格式 | 说明 |
|---|---|---|---|
| **主教材** | 本项目写的课程、知识卡、示例 | Lesson JSON + MusicXML | 不依赖外部 PDF；可解析、可改、可翻译 |
| **练习库** | 五指/音阶/和弦/节奏训练 | MusicXML + JSON | 原创或从 PD 方法书选编 |
| **曲目库** | 59 首教学编配 | MusicXML + MIDI | 民歌/古典主题，本项目编配 |
| **拓展库** | OpenScore/Mutopia/MuseScore 等 | MusicXML/MIDI（按来源） | 进阶/补充；许可逐项核对 |
| **理论参考** | OMT、Musicca、维基教科书、MOOC | 网页/PDF | 只链接/参考，不作为运行时内容 |
| **图片谱** | 用户导入/扫描 | PNG/JPG/PDF | 只显示；不进核心课程 |

### 4.2 来源优先级

1. **本项目原创/编配**（最高优先）：所有核心曲目/训练，从 PD/传统旋律或原创动机
   在 MuseScore 中制作，导出 MusicXML + MIDI。可解析性 100%。
2. **已有 MusicXML/MIDI 的公共领域源**：OpenScore（CC0）、MuseTrainer（70+ `.mxl`，
   候选需核验）、schoolbandclass（11,500+ PD 候选，需核验）、
   MuseScore 公共领域曲目（逐曲核验）、Pianovera（55 MIDI 候选）。
3. **只有 PDF/LilyPond 的 PD 方法书**：Beyer/Czerny/Hanon 等，选少量条目，
   用 MuseScore 重新录入或 OMR + 人工修正；只作为练习库的种子。
4. **PDF/图片**：只做参考/展示；不进入"可跟谱"核心路径。

### 4.3 外部教材的处理

- Open Music Theory / musictheory.net / Musicca / 维基教科书 / 中国大学 MOOC：
  用于课程设计参考与延伸阅读，**不把其文字/题目/视频打包进软件**。
- Beyer/Czerny/Hanon：PD 作品；选短小条目，**重新录入为 MusicXML**，
  标注来源/版本/编配；不整本打包 PDF。
- OpenScore：CC0，MusicXML 可用；偏进阶，作为阶段 6+ 的拓展/分析。
- Mutopia：有 LilyPond/PDF/MIDI，**没有原生 MusicXML**；用 MIDI/PDF 参考，
  重新录入或转换后校验，不作为"直接可解析"的批量来源。
- IMSLP：绝大多数是 PDF 扫描；用 Audiveris OMR 或人工录入，必须修正与校验。
- MuseScore 用户曲谱：可导出 MusicXML，但许可逐曲不同；入库前核验。

## 5. 生产流水线

```
选题 → 来源/许可 → 编配/录入 → MusicXML → MIDI 示范 → 元数据/映射
     → 下一键/左右手 → 课程注释 → 自动校验 → 试弹 → ready
```

### 5.1 选题

- 从课程表（`TEACHING_CURRICULUM.md`）取 ID；不临时加无课程归属的曲目。
- 先确认音域/手/难度/映射是否适合 32 键；不适合则换曲或编配。
- 早期曲目优先级进、短句、少跳进；避免需要踏板/力度才成立的曲目。

### 5.2 编配 / 录入

- 用 MuseScore 新建：声部按左右手分 part（或同 part 分 staff/voice）。
- 自动伴奏曲：把手演奏的右手放 **P1**，软件自动演奏的左手放 **P2**，
  课程条目写 `accompaniment="P2"`（见 `PracticeItem`）；MIDI 示范仍含
  双手全部音符，保证与 MusicXML 逐音一致。
- 32 键编配：确认音域、分区、八度/移调；必要时简化内声部/装饰音。
- 所有音符时值明确；连音线、反复、跳房子写清楚；不依赖排版位置。
- 速度标记：练习速度 + 目标速度；节拍器可跟。

### 5.3 导出

- MusicXML：`.musicxml`（未压缩）或 `.mxl`（压缩）；两者都能解析。
- MIDI：示范/伴奏；一轨一手或按声部；固定 velocity（默认 100）。
- 文件命名：`p3-01.musicxml`、`p3-01-demo.mid`、`p3-01-backing.mid`。
- 不导出依赖特定字体/排版的元素；不使用图片作为唯一谱面。

### 5.4 元数据

- 按 [CONTENT_SCHEMA.md](CONTENT_SCHEMA.md) 填：
  `mapping`、`range`、`hands`、`tempo`、`concepts`、`next_key`（derived/显式）、
  `source`、`license`、`visibility`、`public_release`、`readiness`。
- 下一键默认由谱面 + 映射生成；特殊训练可显式给光条序列。
- 左右手标注与谱面声部一致；分区与 mapping 一致。

### 5.5 课程注释

- 每首曲/训练至少：练什么、听什么、练习顺序、困难小节、常见错误、自检。
- 参考课程模板（CURRICULUM §22B/§22C）。
- 注释与谱面/音频在同一 ID 下，避免"课文说第 3 小节、谱面却是另一个版本"。

### 5.6 校验

见 §6。未通过校验的内容状态只能是 `encoded`，不能是 `ready`。

## 6. 自动校验与人工试弹

### 6.1 自动校验

- **MusicXML 结构**：XML 合法；调号/拍号/小节数/声部；每个音符有时值；
  连音/反复/跳房子可解析；无缺失 rest 导致的时间线空洞。
- **音乐一致性**：小节总时值 = 拍号；连音线闭合；反复跳转不越界；
  左右手声部齐全；速度标记存在。
- **32 键可弹性**：映射后所有 MIDI 0–127；每个音有光条；音域 ≤ 32 个不同音高
  （或明确标注需要自动跟随/简化）；分区不越界。
- **下一键**：序列与谱面事件一一对应；时间顺序正确；和弦同时亮多个。
- **MIDI**：可播放；长度与谱面一致；轨道/音色正确；无力度曲线。
- **课程引用**：lesson/drill/piece ID 存在；许可/可见性字段存在；
  公开构建不引用私有内容（见 RELEASE_POLICY）。

### 6.2 解析器回归

- 用 W3C MusicXML 测试套件中的一小部分作为解析器回归基线
  （`w3c-cg/musicxml/tests`）；不要求覆盖全部，但覆盖常用记号。
- 每次解析器改动跑：音高/时值/连音/反复/多声部/拍号/调号。
- 用 MuseScore 重新打开导出的 MusicXML，确认没有丢失/错位。

### 6.3 人工试弹

- 在真实 32 键琴 + 电脑键盘上各弹一遍；检查：
  - 光条/音名/左右手提示是否对应；
  - 跟弹/伴奏/循环/速度是否可用；
  - 音域/映射是否需要调整；
  - 难度是否与阶段匹配；
  - 听觉上是否像原曲（编配合理性）。
- 通过后状态 `ready`；失败回到 `encoded` 并记录原因。

## 7. 内容状态与发布门槛

| 状态 | 含义 | 是否可在学习页出现 |
|---|---|---|
| `planned` | 只有目录条目 | 否（显示"制作中"） |
| `sourced` | 来源/许可已记录 | 否 |
| `encoded` | 有 MusicXML/MIDI/JSON | 否（除非标注未校验） |
| `validated` | 自动校验 + 人工试弹通过 | 是（可标"试用"） |
| `ready` | 课程注释/示范/映射完整 | 是 |
| `deprecated` | 不再使用 | 否 |

**阶段门槛**：

- 阶段 0–2：全部训练就绪（8/20/18）才显示为"可完整学习"。
- 阶段 3–6：至少 8 首曲目 + 10 条训练就绪才显示为"可学习"；
  完整阶段需要全部 15/14/15/12 曲目就绪。
- 阶段 7–8：至少 3 个项目就绪。
- **MVP**：阶段 0–3 全量就绪（18 曲 + 64 训练）。
- **完整版**：59 曲 + 62 谱面训练 + 54 生成训练 + 8 项目全部 `ready`。
- **当前状态（2026-11-08）**：已有 **35/42** 学习页项目就绪（阶段 0 6/6、
  1 4/4、2 4/4、3 7/7、4 5/5、5 5/5、6 4/4）；曲库 **22 个可跟随文件
  （12 曲 + 10 训练）+ 2 首制作中**。其余条目仍按本计划生产，未就绪不进入
  核心路径。`梦中的婚礼 · 片段` 标为私有，公开构建必须排除。

**公开构建门槛**：

- 所有 `public_release != allowed` 的内容被排除或替换；
- 许可清单完整；私有目录不进入公开包；
- 校验报告无私有引用；见 [RELEASE_POLICY.md](RELEASE_POLICY.md)。

## 8. 工具与格式

| 工具 | 用途 | 注意 |
|---|---|---|
| **MuseScore** | 录入/编配/导出 MusicXML + MIDI | GUI 或 CLI；`mscore -o out.musicxml in.mscz`；批量 `-j job.json`；<https://handbook.musescore.org/appendix/command-line-usage> |
| **Audiveris** | PDF/图片 OMR → MusicXML/MIDI | AGPL-3.0；识别后必须人工修正；只用于 PD/可用来源；<https://github.com/Audiveris/audiveris> |
| **W3C MusicXML 测试** | 解析器回归 | `w3c-cg/musicxml/tests`；按需选取；<https://github.com/w3c-cg/musicxml/tree/main/tests> |
| **xmllint / MuseScore 重开** | XML/结构检查 | 不替代音乐校验 |
| **本项目解析器** | 解析/下一键/映射/判定 | 以 `CONTENT_SCHEMA` 为准 |
| **FluidSynth** | 示范/伴奏/回放 | 固定 velocity；48 kHz |
| **MuseTrainer**（musetrainer.github.io） | 可选 MusicXML 来源 | 候选；逐项核验许可/编配版权 |
| **schoolbandclass**（schoolbandclass.com） | 可选 MusicXML/PDF 来源 | 候选；逐项核验站点条款 |
| **MuseScore 公共领域曲目** | 可选 MusicXML/MXL 来源 | 逐曲核验许可/编配 |
| **OpenScore** | CC0 MusicXML/进阶 | 下载 `.mxl` 或 MuseScore 转换 |
| **Mutopia** | LilyPond/PDF/MIDI | 无原生 MusicXML；需转换/重录 |

> MuseScore CLI 与 Audiveris 的具体版本/参数在实现时锁定；命令示例仅说明路径。
