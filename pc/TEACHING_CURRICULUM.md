## 1. 这套教学要解决什么

一个零基础用户买了 32 键电子琴，打开软件后通常会卡在三件事：

1. 不知道软件怎么用（按钮多、英文多、怕按错）。
2. 不知道学什么、先学哪首、每天练什么。
3. 看得到谱，但不知道谱上的音对应哪条键、哪只手、弹多久。

因此课程不是"曲谱合集"，而是：

```
阶段目标 → 指导书（知识 + 示范） → 基本功训练 → 曲目 → 反馈 → 下一阶段
```

每个阶段都回答四个问题：

- **学什么**（目标与知识点）
- **怎么练**（步骤、速度、分手/双手、循环）
- **练什么**（足够的短训练 + 完整曲目）
- **怎么算过关**（可自评，不制造考试焦虑）

## 2. 学习路径

```
基础（阶段 0–2）          演奏（阶段 3–6）              创作（阶段 7–8）
┌───────────────┐   ┌───────────────────────────┐   ┌──────────────────┐
│ 0 上手         │   │ 3 右手旋律                 │   │ 7 录音与编曲      │
│ 1 五线谱与音名 │──▶│ 4 左手与和弦               │──▶│ 8 多乐器合成      │
│ 2 节奏与拍号   │   │ 5 双手合奏（含伴奏）       │   │                  │
└───────────────┘   │ 6 表现与完整曲目           │   └──────────────────┘
                    └───────────────────────────┘
主线：识谱 → 单手 → 双手 + 伴奏 → 录音回放 → 多乐器合成
```

- **阶段 0–2**：不要求弹完整曲；重点是看得懂、按得对、跟得上拍。
- **阶段 3–6**：从右手旋律到双手 + 伴奏，最后完整演奏并录音。
- **阶段 7–8**：把演奏变成作品：多轨、音色、混音、导出。
- 所有阶段可在 UI 中查看；推荐按顺序，但不强制锁死。用户可跳到感兴趣的曲目。

## 3. 教学原则

1. **先听/唱，再弹**：每首曲先听示范或唱一遍，再上手；识谱不是背位置。
2. **一次只加一个难度**：新节奏、新音域、新手的动作分开练，不在一首曲里同时加三样。
3. **分手 → 慢速 → 循环 → 合手 → 原速**：这是所有曲目的标准流程。
4. **短时高频**：每天 15–20 分钟，比周末一次两小时有效。
5. **错误要具体**：不说"弹错了"，说"第 3 小节左手晚了 80 ms / 漏了 F"。
6. **不追速度**：先正确、再稳定、再速度；速度是结果，不是目标。
7. **没有力度就用时间和延音**：这台琴对压力不敏感；强弱靠按住时长、连奏/断奏、延音键。
8. **每节课有可完成的小目标**：3–8 小节，能在一两次练习内完成。
9. **录音是老师**：阶段 5 开始定期录回放；自己听比只看分数有效。
10. **不羞辱、不排名**：反馈用"下一步怎么做"，不用红叉和排名。

## 4. 32 键电子琴的教学适配

### 4.1 音域不是固定的

物理上只有 32 个键，但"每个键发什么音"由**音域映射**决定。课程里的每首曲都带：

- 推荐映射（半音阶 / C 大调 / 自定义）
- 推荐音域（如 C3–G5）
- 左右手分区（如 1–12 左手，13–32 右手）
- 八度/移调（如需要）

软件在打开曲目时自动套用；光条上显示当前音名。用户不需要自己算。

### 4.2 左右手与分区

- 默认建议分区：**16/16**（光条 1–16 左手，17–32 右手），可改。
- 早期右手曲目：只使用右手区，左手区可留空或做长音。
- 双手曲目：每首曲目自带分区；光条按左手青绿、右手暖金显示。
- 电脑键盘的"左右分区"预设可把低音放键盘左半、高音放右半；不强制。
- **已实现音域映射「左右分区」**（2026-11-08）：bar 16 分界，左区
  C3–D#4、右区 C5–D#6；键位布局的左右分区仍是规划。按曲目自动套用
  `mapping.split`（schema §6.1）尚未接加载器。

### 4.3 没有力度

- 所有音固定 velocity（默认 100，可在高级设置改全局值）。
- 强弱表达方式：
  - 按住时长（长音更饱满，短音更轻巧）
  - 连奏/断奏（legato / staccato）
  - 延音键（SUS）
  - 速度与乐句呼吸
  - 音色与混响（创作阶段）
- 课程明确告诉用户："不要期待按得重更响；用时间和延音做表情。"

### 4.4 光条与电脑键盘

- 光条从左到右 = 物理键 1–32；不画钢琴黑白键。
- 学习模式在光条上显示音名/左右手；演奏模式默认干净。
- 电脑键盘默认三行 32 键，可换左右分区/白键简化/自定义；见 UI 设计 §7。
- 没有硬件时，电脑键盘就是主乐器；所有课程都能用电脑键盘完成。
- 鼠标不弹琴；练习时不需要鼠标。

### 4.5 曲目编配原则

- 优先选择音域 ≤ 32 个半音、或可通过移调/八度覆盖的曲目。
- 双手曲目可使用分区映射，把左手放在低音区、右手放在高音区。
- 超过 32 个不同音高的曲目：
  - 简化（删内声部/重复音/装饰音）
  - 移调/八度
  - 用自动跟随窗口（P2）
  - 或标为"进阶/需自动跟随"
- 早期曲目避免大跳、快速换位、复杂和弦；先建立位置感。
- 每首曲目标注：难度、音域、手、映射、速度、时长、概念、来源/许可。

### 4.6 教材与曲谱的选择标准（可解析优先）

| 角色 | 选择 | 格式 | 说明 |
|---|---|---|---|
| **主教材** | 本项目课程/知识卡/示例 | Lesson JSON + MusicXML | 不依赖外部 PDF；可解析、可改 |
| **练习库** | 本项目原创 + PD 方法书选段 | MusicXML + MIDI | Beyer/Czerny/Hanon 选段需重录，不直接读 PDF |
| **曲目库** | 59 首教学编配 | MusicXML + MIDI | 民歌/古典主题；本项目编配 |
| **拓展库** | OpenScore / MuseTrainer / schoolbandclass / MuseScore | MusicXML/MIDI（按源核验） | 只收可解析且许可允许的 |
| **理论参考** | OMT/Musicca/维基/MOOC | 网页/PDF | 只参考；不进入运行时 |
| **图片谱** | 用户导入/扫描 | PNG/JPG/PDF | 只显示；不进核心 |

**硬规则**

- 核心课程不使用"只有 PDF/图片"的教材或曲谱；无法解析就不能跟谱/下一键/判定。
- 外部教材即使有 PDF，也只作为编写参考；运行时的课程文字由本项目 JSON 重写。
- 方法书选段、PDF 曲谱：用 MuseScore 重录或 Audiveris OMR + 人工修正，
  导出 MusicXML/MIDI 后才能入库。
- 主教材/练习/曲目必须有 `readiness` 状态；未 `ready` 不进入核心路径。
- 详细生产/校验见 [CONTENT_PIPELINE.md](CONTENT_PIPELINE.md)。

### 5.1 机器可读覆盖（硬要求）

课程功能（跟谱、下一键、自动滚动、自动映射、伴奏、判定）依赖可解析的谱面，

| 类型 | 数量 | 必需格式 | 说明 |

| 创作项目 | 8 | Project JSON + MIDI | 多轨、回放、导出 |

| 生成训练 | 54 | JSON 规格（题型/答案/判定） | 识谱点选、节奏拍击、项目操作 |
| **合计** | **67 曲目/项目 + 116 训练** | | |

- 谱面训练 62 = 阶段 1 的 D1-11/D1-19/D1-20 + 阶段 2 的 D2-18 +
  阶段 3–6 全部（58）；其余训练为生成式规格。
- 生成训练 54 = 阶段 0（8）+ 阶段 1（17）+ 阶段 2（17）+ 阶段 7（6）+ 阶段 8（6）。
- **100% 核心谱面内容**必须能被软件解析；**不允许**把 PDF/图片当作主练习谱。
- 图片/PDF 只能做补充展示（"仅显示"），不能进入跟练/判定。

- 所有内容有 `readiness` 状态：`planned → sourced → encoded → validated → ready`；

## 6. 阶段 0：上手（3 课 / 8 训练 / 3 迷你曲）

**目标**：知道软件怎么用，能发出声音，知道"光条、音名、音色、延音、全部静音"。

**前置**：无。

### 6.1 课程

| 课 | 标题 | 内容 | 产出 |
|---|---|---|---|
| 0.1 | 第一声 | 连接琴或用电脑键盘；按光条；音量；全部静音；没声音怎么办 | 听到一个音 |
| 0.2 | 光条、音名、键位 | 32 条从左到右；音名；电脑键位图；左手/右手区；鼠标不弹琴 | 找到 C5 |
| 0.3 | 第一段旋律 | C–E–G–E–C；跟光条；录音/回放一次 | 弹 5 个音 |

### 6.2 训练

| ID | 训练 | 操作 | 目标 |
|---|---|---|---|
| D0-01 | 32 条点名 | 从 1 按到 32，听音名 | 认识位置 |
| D0-02 | 电脑键位 | 按 Z X C … 找对应光条 | 键位图 |
| D0-03 | 按下/松开 | 长按 1 秒再松开 | 理解 note on/off |
| D0-04 | 延音 | 按住 Shift 弹 3 个音 | 延音 |
| D0-05 | 全部静音 | 按住几个音，按 Esc | Panic |
| D0-06 | 换音色 | Ctrl+P 切 3 次 | 音色 |
| D0-07 | 八度 | Ctrl+[ / ] 各一次 | 音域 |
| D0-08 | 三音模仿 | 软件弹 C-E-G，用户模仿 | 听/弹 |

> 当前应用已接入：D0-02「找到中央 C」（C4 → D4 → E4 → C4）、
> D0-04 + D0-05「延音与全部静音」（Shift → 按 C4 → Esc），以及
> 《小星星》第一句跟弹；其余 D0 训练仍为规划。

### 6.3 迷你曲

| ID | 曲名 | 说明 |
|---|---|---|
| P0-01 | C–E–G | 三个长音 |
| P0-02 | C–E–G–E–C | 5 音 |
| P0-03 | 小星星前两句（右手） | 仅 6 个音 |

### 6.4 通关

- 不看鼠标，用琴或电脑键盘弹出 P0-03。
- 能说出"全部静音"和"延音"的区别。
- 知道没声音时先检查音频/设备/输入法。

## 18. 练习方法与常见问题

### 18.1 标准练习流程

1. **听/唱**：听示范，唱音名/节奏。
2. **读谱**：指出下一键、手、时值。
3. **分手**：右手/左手各 2–4 小节。
4. **慢速**：50–60%，循环困难小节。
5. **合手**：先长音/和弦，再原速。
6. **完整**：不中断；错了继续。
7. **录音**：回放，找 1 个改进点。
8. **标记**：完成/再练。

### 18.2 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 按键没声音 | 音频、输入法、设备、音域越界 | 检查音频/设备/输入法；看光条是否变暗 |
| 总是漏音 | 手位/映射不熟 | 先分手，看音名，慢速 |
| 节奏不稳 | 跟节拍器太少 | 60 BPM 单音节奏，拍手 |
| 双手合不上 | 直接合手 | 分手→左手长音→右手旋律→合手 |
| 左手太重/太响 | 没有力度 | 用时长/断奏；降低伴奏音量 |
| 速度上不去 | 只练原速 | 慢速循环，逐步 5% 加 |
| 音域不够 | 32 键限制 | 换映射/八度/简化；看曲目建议 |
| 电脑键盘冲突 | 输入法/无冲 | 切英文输入法；和弦用实体琴 |
| 看谱慢 | 识谱训练少 | 每天 5 分钟 D1 训练 |
| 练一会儿就乱 | 一次加太多 | 一次只加一个难点 |

## 20. 内容生产流程与版权

### 20.1 每首曲目/训练的入库流程

```
选题 → 许可/可见性记录 → 编配（32 键） → MusicXML → 校验
     → 示范/伴奏 MIDI → 元数据/映射 → 下一键/左右手 → 教学注释
     → 难度评审 → 试弹 → 许可清单 → readiness=ready → 发布
```

### 20.2 版权与私有/公开版

**私有版（你现在使用）**

- 可以纳入你能合法访问的教材、曲谱、录音，用于个人学习；不需要先拿到公开许可。
- 仍然要记录：来源、版本、格式、获取日期、是否可公开、公开替代方案。
- 私有内容放 `resources/private/`，标记 `visibility: private`、
  `public_release: remove|replace`；将来公开版按清单剔除/替换。

**公开版（将来分发）**

- 只收：本项目原创/编配、公共领域（PD）、CC0、明确允许再分发的 CC BY/CC BY-SA。
- 不公开：版权保留的教材/曲谱/改编/歌词/图片/录音、仅限个人/订阅/DRM 的内容、
  CC BY-NC、版权不明内容、现代流行/影视/动漫配乐。
- 公共领域判断按目标发行地区；IMSLP 的"PD"按作品/版本/辖区分别核对。
- Mutopia 逐曲许可不同；OpenScore 为 CC0；MuseScore 用户曲谱逐曲核验。
- 每个内容在 `resources/licenses/manifest.json` 记录：
  `id, title, composer, source_url, source_format, license, attribution,
   modifications, visibility, public_release, public_alternative,
   verified_by, verified_at, territory`.
- 编配/简化/移调属于修改；在清单中注明"本项目编配"。
- 不使用歌词；只做器乐旋律。
- 公开构建的自检/剔除流程见 [RELEASE_POLICY.md](RELEASE_POLICY.md)。

**与机器可读的关系**

- 私有内容如果要用于跟谱/判定，同样必须转成 MusicXML/MIDI；
  只有 PDF/图片的私有内容只能"仅显示"，不能作为主练习。
- 公开替代内容也必须是可解析的 MusicXML/MIDI，而不是换一张 PDF。

### 20.3 32 键编配规范

- 标明推荐映射、音域、左右手分区、八度/移调。
- 每首曲/谱面训练必须有 MusicXML + MIDI；生成训练必须有 JSON 规格。
- 图片/PDF 只能补充显示；不能作为核心练习谱。
- 旋律优先；内声部可删；和弦可简化；避免超过 32 个不同音高。
- 左手低音不低于 C2（实际以映射为准）；右手不高于 C7；避免极端音区。
- 早期曲目速度 ≤ 90 BPM；每首 8–32 小节。
- 所有音符必须在 MIDI 0–127；映射后检查越界。
- 提供 `next_key` 数据（每个音符对应光条/音名）供提示带使用。
- 难度 1–5：1 = 五指/四分；2 = 八分/简单和弦；3 = 双手/三拍；
  4 = 分解/延音/完整；5 = 多声部/快速/复杂映射。

### 20.4 教学注释

每首曲目至少包含：

- 这首曲练什么（1–2 句）。
- 难点小节 + 练法。
- 推荐速度/分手顺序。
- 常见错误（1–3 条）。
- 自检标准（音准/节奏/完整）。
- 示范（MIDI/自动演奏）与推荐音色。

### 20.5 质量检查清单

## 22. 样例课：阶段 0 第 1 课（完整脚本）

**标题**：第一声——让 32 条光条响起来

**时长**：8–10 分钟

**目标**：
1. 知道琴/电脑键盘都能发声。
2. 按任意光条听到声音，松开停止。
3. 知道"全部静音"和"延音"。

**准备**：软件打开；琴连接或电脑键盘可用；音量 30%。

**步骤**：

1. **看**（1 分钟）
   - 屏幕底部有 32 条半透明光条，从左到右是键 1–32。
   - 光条不是钢琴键；按下去才会出现彩色光柱，松开会消失。
   - 没有琴也可以用电脑键盘：默认 `Z X C V B N M , . /` 等三行。

2. **听**（2 分钟）
   - 在默认半音阶映射下，按光条 8（或电脑键 `,`），听到 C5。
   - 长按 2 秒，再松开；观察光柱出现后消失。
   - 按 `Esc`（全部静音），确认声音停止。

3. **做**（3 分钟）
   - 依次按 8、10、12（C5、D5、E5），每个 1 秒。
   - 再按 12、10、8 下行。
   - 用 `Shift`（延音）按住，再弹 8-10-12，听音延续。

4. **玩**（2 分钟）
   - 按 `Ctrl+P` 换一个音色（钢琴 → 电钢），再弹一次。
   - 按 `Ctrl+[` / `Ctrl+]` 移八度，听音高变化。
   - 回到原八度。

5. **检查**（1 分钟）
   - 你能不看鼠标找到 8、10、12 吗？
   - 你知道松手后声音为什么停吗？
   - 你能说出"全部静音"和"延音"的区别吗？

**常见错误**：
- 没声音：检查音频输出、电脑输入法、是否按在光条/键盘上、是否静音。
- 按了没反应：可能焦点在输入框/设置页；回到演奏页或按 `Ctrl+1`。
- 光柱太快消失：这是设计；特效不占空间。

**下一步**：阶段 0 第 2 课"光条、音名、键位"。

## 22A. 样例课：阶段 1 第 2 课（高音谱号）

**标题**：高音谱号——从线和间读出音名

**时长**：10–12 分钟

**目标**：
1. 认识五线谱的五条线、四个间。
2. 记住高音谱号线/间的音名（C4–F5 范围）。
3. 看到 C4–C5 的音，能在 3 秒内找到光条。

**准备**：阶段 1 第 1 课完成；光条辅助标签开启；速度不限。

**知识卡（讲给学生看）**：

```
高音谱号（treble clef）：
五线：E4  G4  B4  D5  F5      （从下往上）
四间：  F4  A4  C5  E5
下加一线：C4（中央 C）
```
中文记忆：
- 线：**E–G–B–D–F**（"Mi–Sol–Si–Re–Fa"）。
- 间：**F–A–C–E**（"Fa–La–Do–Mi"）。
- 先记"下加一线是 C4"，再向上数：C4、D4、E4（一线）、F4（一间）、G4（二线）……
- 不要背"第几线=第几个音"；背"线与间的音名"，用眼睛找。

**步骤**：

1. **看**（2 分钟）
   - 屏幕上高亮五条线与四个间；点线/间，显示音名与光条位置。
   - 先只看 C4–C5 一个八度，不引入加线。

2. **找**（3 分钟）
   - 软件随机显示 8 个音（C4–C5），用户按对应光条。
   - 答对：光条亮 + 音名；答错：显示正确位置，允许重试，不扣分。
   - 目标：8 个中至少 6 个一次正确。

3. **读**（3 分钟）
   - 显示 4 小节简单旋律（C 大调，四分/二分），先唱音名，再弹。
   - 只要求音名正确，不要求速度。

4. **写/说**（2 分钟）
   - 给 5 个音名，用户说出"第几线/第几间"；反过来再练 5 个。
   - 用光条指位置，不弹也可以。

5. **检查**（1 分钟）
   - 10 个随机音，正确 ≥ 8 个；平均反应 < 3 秒。
   - 能解释"下加一线为什么是 C4"。

**常见错误**：
- 把"间"和"线"数错：用手指沿着线走一遍，不要猜。
- 把 C4 和 C5 混：C5 在三间，C4 在下加一线；先找 C4，再向上数。
- 只看位置不看谱号：低音谱号会换一套音名；先确认谱号。

**评估**：
- 识谱正确率 ≥ 80%；不需要计时考试。
- 如果低于 80%，重复本课 + D1-01/D1-02，不进入下一课。

> 当前软件版 D1-01 为 10 题；首次答对率与首答反应时间会记录，完成条件
> 仍是“10 题全部解出”。80% 与 3 秒标准由可选考核承载（H7d），不在普通
> 练习里伪装成已强制执行；考核不阻止普通练习完成。

**下一步**：阶段 1 第 3 课"音名与八度"。

## 22B. 课程指导书编写模板

每节课按以下结构写，控制在 800–1500 字（不含谱例）：

```
1. 标题（≤12 字）
2. 目标（2–3 条，可检查）
3. 先修（需要完成哪课/哪条训练）
4. 知识卡（1–3 张；每张 100–300 字 + 一张图/谱例）
5. 示范（一段 2–8 小节；说明听什么、看什么）
6. 练习步骤（3–5 步；每步有速度/分手/循环）
7. 常见错误（2–4 条；每条给修正动作）
8. 自检（2–3 条；可量化）
9. 下一步（下一课/推荐训练/曲目）
```

写作规则：

- 先给"做什么"，再解释"为什么"；不要先讲一大段历史。
- 每段不超过 5 行；用短句。
- 术语第一次出现给中文解释 + 英文小字。
- 所有例子都要能在 32 键上弹；不能弹的例子不用。
- 不写"很简单/很容易"；写具体动作。
- 不复制外部教材的段落；用自己的话重写。

## 22C. 曲目指导书模板

每首曲目入库时附一页指导书：

```
曲名 / 作曲家 / 来源 / 许可
难度 / 音域 / 映射 / 左右手 / 速度 / 时长
这首曲练什么（1–2 句）
听示范时注意什么（1–2 条）
练习顺序：分手 → 慢速 → 困难小节 → 合手 → 原速
困难小节：第几小节 + 怎么练
常见错误：2–3 条 + 修正
自检：音准/节奏/完整/表情
下一步：推荐曲目/训练
```

示例（P3-01 小星星）：

- 练什么：四分/二分时值、级进、4 小节乐句。
- 听示范：每句结尾的长音；不要赶。
- 顺序：右手 4 小节 → 循环 1–2 小节 → 8 小节 → 80%。
- 困难：第 3 小节两个相同音不要连成一拍。
- 错误：最后一句抢拍；用节拍器 60。
- 自检：音准 ≥ 90%，不停顿，长音够拍。
- 下一步：P3-02《两只老虎》/D3-01。
